### 2.3 Tones

Zolai has **three tones** plus a neutral tone:

| Tone | Mark | Example | Meaning |
|------|------|---------|---------|
| High | acute (´) | `pa` (father) | — |
| Mid | unmarked | `pa` (father) | — |
| Low | grave (`) | `pa` (father) | — |
| Neutral | unmarked | `pa` | — |

**Note:** Tone is not always marked in ZVS 2018 orthography, but it is phonemically distinctive.

### 2.4 Syllable Structure

| Pattern | Example | Meaning |
|---------|---------|---------|
| CV | `pa` | father |
| CVC | `pak` | just now |
| CVN | `pan` | from |
| CVCC | `pant` | — |
| CCV | — | rare |
| V | `a` | he/she |
| VC | `an` | — |

### 2.5 Phonotactic Constraints

1. **[t] + [i]:** These sounds do not combine in Zolai.
2. **[c] + [a, e, o, aw]:** The initial consonant `c` only pairs with `i` and `u`.
3. **[uh] + [i]:** The plural marker `uh` never co-occurs with 1st person inclusive `i`.

## 3. Writing System (ZVS 2018)

### 3.1 Overview

The Zolai Vernacular Standard (ZVS) 2018 is the official orthography for Tedim Zolai. It was adopted to unify spelling across educational, religious, and media contexts.

### 3.2 Key Principles

| Principle | Rule | Example |
|-----------|------|---------|
| `noun khat word khat` | One concept = one word | `vantung` (NOT `van tung`) |
| No spaces in compounds | Compounds are single words | `biakinn` (NOT `biak inn`) |
| Forbidden forms | 8 deprecated spellings | `pasian` ≠ `pathian` |
| Consistent vowels | Standard vowel spelling | `gam` (NOT `ram`) |
| Consistent consonants | Standard consonant spelling | `tapa` (NOT `fapa`) |

### 3.3 ZVS 2018 Forbidden Forms

| Forbidden | Correct | Meaning | Rule |
|-----------|---------|---------|------|
| `pathian` | `pasian` | God | `p` → `s` (not `th`) |
| `ram` | `gam` | earth, land | `r` → `g` (not `r`) |
| `fapa` | `tapa` | life/son | `f` → `t` (not `f`) |
| `bawipa` | `topa` | Lord | different word entirely |
| `siangpahrang` | `kumpipa` | Savior | different word entirely |
| `cu/cun` | `tua` | that (conjunction) | `cu` → `tua` |
| `suah` | `suahtakna` | holiness | context-dependent |
| `nunnak` | `nuntakna` | life | context-dependent |

### 3.4 Punctuation

| Mark | Name | Usage |
|------|------|-------|
| `.` | Period | Sentence end |
| `,` | Comma | Clause separation |
| `?` | Question mark | Question end |
| `!` | Exclamation | Exclamation end |
| `:` | Colon | List/introduction |
| `;` | Semicolon | Clause separation |
| `—` | Dash | Parenthetical |
| `"..."` | Quotation | Direct speech |

## 4. Complete Grammar Overview

### 4.1 Word Order: SOV

Zolai is strictly **Subject–Object–Verb** (SOV). The verb always comes last.

| Pattern | Example | Translation |
|---------|---------|-------------|
| S + V | `Pasian om hi.` | God exists. |
| S + O + V | `Gam ka mu hi.` | I see the land. |
| S + O + V (ergative) | `Pasian in leitung a piangsak hi.` | God created the earth. |
| S + IO + DO + V | `Pasian in amaute thupha a pia hi.` | God gave them blessings. |

### 4.2 Pronoun System

| Person | Pronoun | Agreement Marker | Example |
|--------|---------|------------------|---------|
| 1SG | `ka` / `kei` | `ka` | `Ka pai hi.` — I go. |
| 2SG | `na` / `nang` | `na` | `Na pai hi.` — You go. |
| 3SG | `a` / `amah` | `a` | `A pai hi.` — He/she goes. |
| 1PL | `i` / `ka` (inclusive) | `i` | `I pai hi.` — We go. |
| 2PL | `na` / `nang` (plural) | `na` | `Na pai hi.` — You (pl) go. |
| 3PL | `a` / `amate` | `a` | `A pai-te hi.` — They go. |

**Pronoun usage:**
- `ka`/`na`/`a` = agreement markers (before verb)
- `kei`/`nang`/`amah` = full pronouns (for emphasis or standalone use)

### 4.3 Ergative Construction

Zolai uses a **split ergative** system. The ergative marker `in` marks the agent of transitive verbs.

```
Pasian in vantung leh leitung a piangsak hi.
[Pasian] [in] [vantung] [leh] [leitung] [a] [piangsak] [hi]
[God] [ERG] [heaven] [and] [earth] [3SG.AGR] [create] [DECL]
"God created the heaven and earth."
```

**When to use `in`:**
- Transitive agents (proper nouns or full noun phrases)
- Emphasized or contrasted subjects
- Optional with agreement markers (`a`, `ka`, `na`)

### 4.4 Tense/Aspect/Mood

| Tense/Aspect | Marker | Example | Frequency (zomidaily) |
|--------------|--------|---------|----------------------|
| Present | `hi` | `A pai hi.` — He goes. | — |
| Past | `ta` | `A pai ta hi.` — He went. | 15,548 (3%) |
| Future | `ding` | `A pai ding hi.` — He will go. | 97,787 (19.1%) |
| Completive | `zo` | `A pai zo hi.` — He has finished going. | 11,516 (2.3%) |
| Experiential | `khin` | `Ka mu khin hi.` — I have seen (before). | — |
| Progressive | `lai` | `A ne lai hi.` — He is eating. | 20,878 (4.1%) |

### 4.5 Negation

**`kei` is the standard negation particle for ALL persons:**

```
Ka pai kei hi.      I don't go.
Na pai kei hi.      You don't go.
A pai kei hi.       He doesn't go.
Ka pai kei ding.    I won't go.
```

**`lo` is also valid (literary/formal):**

```
Pai lo hi.          Goes not.
Pai lo ding.        Will not go.
```

**CRITICAL:** `lo` does NOT take `a` agreement:
- ✅ `Pai lo hi.` — Correct
- ❌ `A pai lo hi.` — WRONG (lo is standalone)

### 4.6 Questions

**Yes/No questions use `hiam`:**

```
Na pai hiam?        Do you go?
```

**Content questions use `bang hang` + verb + subject + `hiam`:**

```
Bang hang pai na hiam?    Why do you go?
```

**CRITICAL:** Content question word order:
- ✅ `Bang hang pai na hiam?` — Correct
- ❌ `Bang hang na pai hiam?` — WRONG

**Rhetorical questions use `diam`:**

```
Na lung a kim diam?    Don't you have a heart?
```

### 4.7 Agglutinative Morphology

Zolai verbs are built from stems + directional particles:

| Component | Examples | Function |
|-----------|----------|----------|
| Directional | `hong`, `va`, `khia`, `lut`, `kik` | Movement direction |
| Verb stem | `pai`, `mu`, `ne`, `gen`, `bawl` | Core meaning |
| Aspect | `ta`, `zo`, `khin`, `lai`, `ding` | Time/aspect marking |
| Particle | `hi`, `hen`, `un`, `in`, `vo` | Mood/evidentiality |

**Compound verb example:**

```
Laisiangtho hawmkhia ding.
[Laisiangtho] [hawmkhia] [ding]
[Bible] [print+publish] [FUT]
"The Bible will be published."
```

## 5. Vocabulary System

### 5.1 Word Formation

| Pattern | Function | Example |
|---------|----------|---------|
| `Verb + -na` | Agent noun | `tuana` (teacher) |
| `Verb + -hna/-na` (Stem II) | Abstract noun | `sihna` (death) |
| `Verb + -sak` | Result noun | `piangsak` (created thing) |
| `Verb + -nading` | Infinitive | `painading` (to go) |
| `ki- + Verb` | Reciprocal/passive | `kibawl` (be made) |
| `N + N` | Compound | `vantung` (heaven) |
| `ADJ + -kia/-zaw` | Comparative | `hoih zaw` (better) |
| `N + te` | Plural | `mite` (people) |

### 5.2 Polysemy (Multiple Meanings)

| Word | Meaning 1 | Meaning 2 | Meaning 3 |
|------|-----------|-----------|-----------|
| `dam` | well/healthy | sound (of voice) | firm/stable |
| `sing` | tree | wooden thing | to rise |
| `khua` | village | place | home |
| `ni` | day/sun | two | fire |
| `man` | price | true/correct | as much as |
| `lai` | book/text | document | letter |
| `lung` | heart | mind | spirit |

### 5.3 Compound Words (Key Examples)

| Compound | Components | Meaning |
|----------|------------|---------|
| `vantung` | `van` (sky) + `tung` (top) | heaven |
| `leitung` | `lei` (ground) + `tung` (above) | earth |
| `pasian` | `pa` (father) + `sian` (great) | God |
| `tapa` | `ta` (beginning) + `pa` (father) | son/life |
| `laisiangtho` | `lai` (book) + `siang` (holy) + `tho` | Bible |
| `biakinn` | `biak` (worship) + `inn` (house) | church |
| `lungdam` | `lung` (heart) + `dam` (well) | happy |
| `sialtaang` | `sial` (learn) + `taang` (place) | school |

### 5.4 Loan Word Adaptation

| Strategy | Example | Source |
|----------|---------|--------|
| Direct borrow | `malaysia`, `covid`, `facebook` | English/Malay |
| Descriptive compound | `kumpi` (government), `thudik` (election) | Native morphemes |
| Hybrid | `zato inn` (hospital), `siavuanpa` (doctor) | Mixed |
