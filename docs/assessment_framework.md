# Zolai Language Assessment Framework
> Last updated: 2026-09-10

## Overview

This document provides a comprehensive CEFR-based assessment framework for Zolai (Tedim), mapping levels A1-C2 to Zolai-specific vocabulary, grammar structures, can-do statements, sample texts, and assessment criteria. All examples use correct ZVS 2018 orthography.

---

## 1. CEFR Levels Mapped to Zolai

### 1.1. Level Overview

| Level | Name | Description | Zolai Equivalent | Notes |
|-------|------|-------------|------------------|-------|
| **A1** | Beginner | Basic phrases, simple interactions | Zolai basics | Survival level |
| **A2** | Elementary | Simple sentences, routine tasks | Zolai elementary | Basic communication |
| **B1** | Intermediate | Complex sentences, opinions | Zolai intermediate | Independent user |
| **B2** | Upper Intermediate | Fluent, abstract topics | Zolai upper intermediate | Confident user |
| **C1** | Advanced | Complex structures, nuance | Zolai advanced | Proficient user |

## 3. Grammar Structures per Level

### 3.1. A1 Grammar

| Structure | Pattern | Example | Notes |
|-----------|---------|---------|-------|
| **Basic sentence** | S + V | `Ka pai hi.` | Simple subject-verb |
| **Negation** | S + V + kei | `Ka pai kei hi.` | Basic negation |
| **Question** | S + V + hiam | `Na pai hiam?` | Basic question |
| **Future** | S + V + ding | `Ka pai ding hi.` | Basic future |
| **Past** | S + V + ta | `Ka pai ta hi.` | Basic past |
| **Possession** | ka/na/a + noun | `Ka pa` (my father) | Basic possession |
| **Plural** | noun + te | `Mite` (people) | Basic plural |
| **Ergative** | S + in + O + V | `Pasian in leitung a piangsak hi.` | Basic ergative |

### 3.2. A2 Grammar

| Structure | Pattern | Example | Notes |
|-----------|---------|---------|-------|
| **SOV word order** | S + O + V | `Gam ka mu hi.` | Standard word order |

| **Question by person** | ka/na/a + V + hiam | `Na pai hiam?` | Person-specific question |
| **Future by person** | ka/na/a + V + ding | `Ka pai ding hi.` | Person-specific future |
| **Past by person** | ka/na/a + V + ta | `Ka pai ta hi.` | Person-specific past |
| **Possession** | ka/na/a + noun | `Ka pa` (my father) | Person-specific possession |

| Structure | Pattern | Example | Notes |

| **Complex sentences** | S + O + V + conjunction | `Ka leh na pai hi.` | Compound sentences |
| **Negation with `lo`** | V + lo | `Pai lo hi.` | Literary negation |
| **Content questions** | bang + V + S + hiam | `Bang hang pai na hiam?` | Content questions |

## 5. Sample Texts per Level

### 5.1. A1 Sample Text

**Title:** Basic Introduction

```
Lungdam!
Ka [name] hi.
Ka [country] mi hi.
Ka [age] kum dam hi.
Ka [occupation] hi.
Na dam hiam?
```

**Translation:**
```
Hello!
I am [name].
I am from [country].
I am [age] years old.
I am [occupation].
Are you well?
```

**Grammar Analysis:**
- Basic sentences: S + V
- Possession: ka + noun
- Questions: S + V + hiam
- Negation: S + V + kei

### 5.2. A2 Sample Text

**Title:** Daily Routine

```
Ka zingsang a kik hi.
Ka tui a ne hi.
Ka kam a ne hi.
Ka sikuul a pai hi.
Ka lai a gen hi.
Ka hlim a kik hi.
Ka kam a ne hi.
Ka sih a pai hi.
```

**Translation:**
```
I wake up in the morning.
I drink water.
I eat food.
I go to school.
I study books.
I return in the evening.
I eat food.
I go to sleep.
```

**Grammar Analysis:**
- SOV word order: S + O + V
- Time expressions: zingsang (morning), hlim (evening)
- Possession: ka + noun
- Verbs: kik (wake), ne (eat), pai (go), gen (know), sih (sleep)

### 5.3. B1 Sample Text

**Title:** Description of Life

```
Nuntakna hi a dam hi.
Ka leh na leh a I nuntakna a nei hi.
I kam a nei hi.
I lungdam a om hi.
I thupha a om hi.
I tapa leh numei a om hi.
I khua a om hi.
I gam a om hi.
```

**Translation:**
```
Life is good.
You and I and we have life.
We have work.
We have heart.
We have blessing.
We have son and daughter.
We have village.
We have land.
```

**Grammar Analysis:**
- Complex sentences: S + conjunction + S + V
- Possession: ka/na/a + noun
- Ergative: S + in + O + V
- Abstract concepts: nuntakna (life), lungdam (heart), thupha (blessing)

### 5.4. B2 Sample Text

**Title:** Creation Account

```
Pasian in vantung leh leitung a piangsak hi.
Pasian in gam a piangsak hi.
Pasian in tui a piangsak hi.
Pasian in sing a piangsak hi.
Pasian in mi a piangsak hi.
Pasian in numei a piangsak hi.
Pasian in a tapa leh numei a pia hi.
Pasian in amaute thupha a pia hi.
```

**Translation:**
```
God created heaven and earth.
God created land.
God created water.
God created trees.
God created people.
God created women.
God gave them son and daughter.
God gave them blessings.
```

**Grammar Analysis:**
- Ergative construction: S + in + O + V
- Complex sentences: Multiple clauses
- Religious vocabulary: pasian (God), vantung (heaven), leitung (earth)
- Abstract concepts: thupha (blessing)

### 5.5. C1 Sample Text

**Title:** Historical Narrative

```
Tua banah, tangthu hi a ciangin a om hi.
Tangthu hi a dam hi.
Tangthu hi a hoih hi.
Tangthu hi a khuavak hi.
Tangthu hi a nuntakna hi.
Tangthu hi a suahtakna hi.

```

**Translation:**
```
Therefore, the history is clear.
The history is good.
The history is fine.
The history is bright.
The history is life.
The history is holiness.
The history is blessing.
The history is son.
```

**Grammar Analysis:**
- Complex subordination: `Tua banah` (therefore)
- Abstract concepts: nuntakna (life), suahtakna (holiness), thupha (blessing)
- Register: formal/written
- Rhetorical devices: repetition, parallelism

## 6. Assessment Criteria

### 6.1. Assessment Areas

| Area | Criteria | Weight | Notes |
|------|----------|--------|-------|
| **Vocabulary** | Range, accuracy, appropriateness | 25% | Word knowledge |
| **Grammar** | Range, accuracy, complexity | 25% | Structural knowledge |
| **Communication** | Fluency, coherence, pragmatics | 25% | Interactive skills |

### 6.2. Scoring Rubric

| Score | Level | Description | Notes |
|-------|-------|-------------|-------|
| 90–100 | C2 | Near-native mastery | Full range, nuanced |
| 80–89 | C1 | Advanced proficiency | Complex structures |
| 70–79 | B2 | Upper intermediate | Abstract topics |
| 60–69 | B1 | Intermediate | Complex sentences |
| 50–59 | A2 | Elementary | Simple sentences |
| 40–49 | A1 | Beginner | Basic phrases |
| 0–39 | Pre-A1 | No proficiency | No basic skills |

| **Reading test** | Comprehension of written Zolai | All levels | Text-based assessment |
