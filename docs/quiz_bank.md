## Writing Prompts (10 Questions)

### W1. Basic Sentence Construction
**Prompt:** Write a sentence about what you do today using "tepen" (today) and a verb of your choice.
- **Example:** Tepen ka ne hi. (Today I eat.)

### W2. Negation Practice
**Prompt:** Write a sentence about something you don't do using "kei" (negation).
- **Example:** Ka mu kei hi. (I don't see.)

### W3. Question Formation
**Prompt:** Write a question asking someone where they go using "Kua" (where) and "hiam" (question marker).
- **Example:** Kua na pai hiam? (Where do you go?)

### W4. Content Question
**Prompt:** Write a question asking someone why they do something using "Bang hang" (why) and "hiam".
- **Example:** Bang hang na ne hiam? (Why do you eat?)

### W5. Future Tense
**Prompt:** Write a sentence about what you will do tomorrow using "ding" (future).
- **Example:** Napi ka pai ding hi. (Tomorrow I will go.)

### W6. Past Tense
**Prompt:** Write a sentence about what you did yesterday using "ta" (past).
- **Example:** Napi ka pai ta hi. (Yesterday I went.)

### W7. Description
**Prompt:** Describe a person using adjectives like "dam" (healthy), "than" (clever), "sang" (new).
- **Example:** Mi dam hi. (Person is healthy.)

### W8. Family
**Prompt:** Write sentences about your family using "pa" (father), "nu" (mother), "tapa" (child).
- **Example:** Pa ka hi. (I am a father.)

### W9. Place Description
**Prompt:** Write sentences about a place using "khua" (village), "gam" (land), "vantung" (heaven).
- **Example:** Khua ka mu hi. (I see the village.)

### W10. Complex Sentence
**Prompt:** Write a sentence using "leh" (and/with) to connect two ideas.
- **Example:** Ka pai leh na pai. (I go and you go.)
