# Zolai Quick Reference Guide
> Last updated: 2026-09-10

**Source:** Zolai-AI corpus + ZVS 2018 standard

## Essential Grammar (One Page)

### Word Order — SOV (Subject–Object–Verb)
```zolai
Gam ka mu hi.           "I see the land."
Pasian in leitung a piangsak hi.  "God created the earth."
```

### Negation
```zolai
Ka pai kei hi.       "I don't go." (all persons)
Pai lo hi.           "Goes not." (literary, NO 'a')
Ka pai kei ding.     "I won't go." (future)
```

### Questions
```zolai
Na pai hiam?         "Do you go?" (yes/no)
Bang hang pai na hiam?  "Why do you go?" (content)
```

## Question Patterns

| Pattern | Example | Meaning |
|---------|---------|---------|
