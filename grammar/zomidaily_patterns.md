## SOV Patterns

### Basic SOV Structure

```
S + O + V + (particle)
```

**Examples from corpus:**
- `mi in gam mu hi.` (Person land see) - "The person sees the land."
- `pasian in vantung a piangsak hi.` (God heaven created) - "God created heaven."
- `zomite te hoihtak hong kipan hi.` (Zomi people agreement came before) - "The Zomi people reached agreement."

### Ergative SOV

```
S + in + O + V + (particle)
```

**Examples:**
- `pasian in leitung a piangsak hi.` (God ERG earth created) - "God created the earth."
- `malaysia in zomite te hong mu hi.` (Malaysia ERG Zomi people came see) - "Malaysia saw the Zomi people."

### Topicalized SOV

```
Top + S + O + V + (particle)
```

**Examples:**
- `tua ahih pen khatvei bek ahih manin...` (That FOC one only is-because...) - "That is because only one..."
- `tuabang pasian in hong piang...` (Maybe God ERG came create...) - "Maybe God created..."

## Negation Patterns

### Standard Negation (kei)

```
S + (in) + O + V + kei + (ding) + (hi)
```

**Examples:**
- `ka pai kei hi.` (I go NEG) - "I don't go."
- `na pai kei ding.` (you go NEG FUT) - "You won't go."
- `a pai kei hi.` (he go NEG) - "He doesn't go."

**Frequency:** 22,128 (4.3%)

### Literary Negation (lo)

```
S + (in) + O + V + lo + (hi)
```

**Examples:**
- `pai lo hi.` (go NEG) - "Goes not."
- `pai lo ding.` (go NEG FUT) - "Will not go."

**Frequency:** 30,908 (6.0%)

### Negation Comparison

## Question Patterns

### Yes/No Questions (hiam)

```
S + (in) + O + V + hiam?
```

**Examples:**
- `na pai hiam?` (you go?) - "Do you go?"
- `pasian in hong piangsak hiam?` (God ERG came create?) - "Did God create?"

**Frequency:** 13,260 (2.6%)

### Content Questions (bang)

```
bang + (hang) + S + V + (hiam)?
```

**Examples:**
- `bang hang pai na hiam?` (what manner go you?) - "Why do you go?"
- `bang pen na hiam?` (what FOC you?) - "What are you?"

**Frequency:** 27,567 (5.4%)

### Rhetorical Questions (diam)

```
S + V + diam + (hi)?
```

**Examples:**
- `na lung a kim diam?` (you heart NEG have?) - "Don't you have a heart?"
- `pasian in hong om diam?` (God ERG came exist?) - "Isn't God there?"

**Frequency:** 1,181 (0.2%)

## Quotative Patterns

### Direct Speech (ci)

```
"..." ci + S + V + (hi)
```

**Examples:**
- `"ka pai ding" ci hi.` ("I will go" said) - "It was said, 'I will go.'"
- `"lungdam" ci in.` ("thanks" said) - "Saying 'thanks'."

**Frequency:** 24,753 (4.8%)

### Indirect Speech

```
S + V + ci + S + V + (hi)
```

**Examples:**
- `a kici ci hi.` (he called said) - "He called, saying..."
- `a thei ci hi.` (he know said) - "He knew, saying..."
