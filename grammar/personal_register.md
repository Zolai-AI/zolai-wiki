# Personal Register — Informal/Emotional Patterns
> Last updated: 2026-09-10

> Source: zolai-wiki/grammar/article_analysis_tangthu.md

## Overview

The personal register in Zolai is characterized by:
- **First person** (`ka`) with emotional expressions
- **Gratitude and emotional particles** (`lung dam`, `itna`, `sangam`)
- **Softening particles** (`ing`, `maw`, `ung`)
- **Title + name compounds** (honorific address)
- **Shorter, fragmented sentences**
- **Code-switching** (English loan words with Zolai gloss)
- **Tag questions** (`ei maw`)
- **Hortative/imperative** forms

## 1. First Person + Emotion Patterns

### Pattern: `ka + [emotion noun] + na + [pronoun]`

| Pattern | Example | Translation | Notes |
|---------|---------|-------------|-------|
| `ka it na` | `ka it na uh` | my love (feeling) | Possessive + emotion |
| `ka sep khawp na` | `ka Sep khawp na uh` | my desire to work | Possessive + desire |
| `ka lung dam` | `ka lung dam mah mah ing` | I am very thankful | First person + gratitude |
| `ka lung gulh na` | `ka lung gulh na hi` | that is my heart's hope | Possessive + hope |
| `ka ki sap` | `ka Ki sap na teng` | on my work | Possessive + work |

### Word-by-Word Analysis

```
ka it na uh ka Sep khawp na uh a om sa mah bangin
[ka] [it] [na] [uh] [ka] [Sep] [khawp] [na] [uh] [a] [om] [sa] [mah] [bangin]
[1SG] [love] [feeling] [3PL] [1SG] [work] [desire] [feeling] [3PL] [3SG.AGR] [exist] [just] [very] [like-IMPF]
"Just as my love and my desire to work exist..."
```

```
ka lung dam mah mah ing
[ka] [lung dam] [mah mah] [ing]
[1SG] [peace/feel] [very very] [IMPF]
"I am very very thankful."
```

### Emotion + Intensifier Patterns

| Emotion | Intensifier | Example | Translation |

## 2. Gratitude Expressions

### Core Patterns

| Pattern | Example | Translation | Context |
|---------|---------|-------------|---------|
| `lung dam mah mah hi` | `lung dam mah mah hi` | very very thankful | Standard gratitude |
| `lung dam lua hi` | `lung dam lua hi` | very thankful | Intensified gratitude |
| `lung dam na Kam Tawh gen zawh ding Hilo` | `ka lung dam na Kam Tawh gen zawh ding Hilo` | I cannot finish speaking with words of gratitude | Overwhelming gratitude |
| `sangam ta` | `sangam ta Nau vai hi` | was grateful, a young person | Past gratitude |
| `nuam ing` | `gen Nuam ing` | it is enjoyable to speak | Enjoyment |

### Word-by-Word: Gratitude Analysis

```
lung dam mah mah hi
[lung] [dam] [mah mah] [hi]
[heart] [peace/well] [very very] [DECL]
"[I am] very very thankful."
```

```
ka lung dam na Kam Tawh gen zawh ding Hilo lung dam lua hi
[ka] [lung dam] [na] [Kam] [Tawh] [gen] [zawh] [ding] [Hilo] [lung dam] [lua] [hi]
[1SG] [peace/feel] [feeling] [Word] [with] [speak] [finish] [FUT] [cannot] [peace/feel] [greatly] [DECL]
"I cannot finish speaking with words of gratitude, [I am] very thankful."
```

## 3. Emotional Particles

| Particle | Function | Example | Notes |
|----------|----------|---------|-------|
| `ing` | Imperative/progressive | `na thum ing` (you pray) | Soft command |
| `maw` | Tag question | `ei maw` (right?) | Seeking agreement |
| `ung` | Hortative | `Ki kum thei ung` (let them wait) | Let it be |
| `cin` | Thus/quotative | `Hi ung cin` (so be it) | Quoting resignation |
| `ni` | Hortative | `thungen suak lai ni` (let prayer continue) | Let it be |

### Word-by-Word: Particle Analysis

```
na thum ing
[na] [thum] [ing]
[2SG] [pray] [IMPF]
"You pray." (gentle request)
```

```
ei maw
[ei] [maw]
[1PL] [TAG]
"Right?" (seeking agreement)
```

```
Ki kum thei ung
[Ki] [kum] [thei] [ung]
[REFL] [wait] [can] [HORT]
"They can wait." (let them)
```

|---------|----------|----------|---------|-------------|

## 8. Register Shift: Formal → Informal

### The article demonstrates a clear register boundary:

| Feature | Formal (Sections 1-4) | Informal (Section 5) |
|---------|----------------------|---------------------|
| **Subject** | Organizations, passive | First person `ka` |
| **Verb forms** | `kibawl`, `khenkik`, `kigawm` | `na sang kha`, `na thum ing` |
| **Connectives** | `Tua ciangin`, `Tua khit` | `Tua khit teh`, casual chains |
| **Vocabulary** | Technical publishing terms | Emotional/personal terms |
| **Sentence length** | Long, complex | Shorter, fragmented |
| **Particles** | `hi` (declarative) | `ing`, `maw`, `ung` |
| **Tone** | Objective, historical | Subjective, grateful |
| **Agency** | Organizations as agents | First person as agent |

### Boundary Marker

The formal section ends with:
```
***** Tedim Laisiangtho Vai , Update *****
```

The informal section begins with:
```
Zani 1 September 2026 in , Bible Society Myanmar Zum na pai thei ing,
```
