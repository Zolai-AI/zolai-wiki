## Song 141 — NA LIAMMA HANG DAM ZO
**Title:** Na Liamma Hang Dam Zo
**English:** How Sweet Your Name

### Lyrics
```
Na liam ma hang dam zo, Halelujah,
Na kam mal tung nong lak zo, Hallelujah;
Kei a ding nong thuak sak zo Kalvary singlamteh ah tuin
Kei ka suak ta zo, Hallelujah.
```

### Word-by-Word (Key Line)
| Zolai | Gloss |
|-------|-------|
| Na | your |
| liam | name |
| ma hang | how |
| dam | sweet |
| zo | (completive) |
| Kam mal | word |
| tung | on/upon |
| nong lak zo | you have carried |
| Kalvary | Calvary |
| singlamteh | on the cross |
| tuin | by means of |
| suak ta zo | you have released/freed |

### New Vocabulary
- `liam` — name (variant of `lim`)
- `Kalvary` — Calvary (loan)
- `singlamteh` — on the cross (`sing` cross + `lamteh` on)
- `suak ta zo` — has released/completed release

### Themes
- Redemption through Calvary, joy and praise (Hallelujah refrain)
