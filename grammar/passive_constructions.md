# Passive Constructions — Voice Patterns in Zolai

> Reference for passive voice patterns in Zolai, drawn from "Tedim Lai Siangtho Tangthu Tom."
> Source: zolai-wiki/grammar/article_analysis_tangthu.md

---

## Overview

Zolai passive voice is characterized by:
- **Agent omission** (the doer is often not mentioned)
- **`ki-` prefix** on verbs (REFL/reciprocal marker functioning as passive)
- **Verb + `hi`** (declarative particle)
- **Ergative `in`** when agent IS mentioned

The passive is extremely common in formal/historical Zolai, especially when the focus is on the **result** rather than the **doer**.

---

## 1. Core Passive Pattern: `[Object] + [ki-Verb] + hi`

### Pattern

```
[Object] + ki-[verb stem] + hi = "[Object] was [verbed]"
```

The `ki-` prefix (REFL/reciprocal) functions as a passive marker when the agent is omitted.

### Examples

| # | Passive Verb | Full Sentence | Translation |
|---|-------------|---------------|-------------|
| 1 | `kibawl` | `bu 1,000 kibawl hi.` | 1,000 copies were made. |
| 2 | `suakkhia` | `a laibu-in suakkhia hi.` | It was printed as a book. |
| 3 | `khenkik` | `India pan khenkik hi.` | Was reprinted from India. |
| 4 | `kigawm` | `Thuciam Lui a kigawm hi.` | New Testament was combined. |
| 5 | `kikhensat` | `khetkik dingin kikhensat hi.` | It was decided to reprint. |
| 6 | `kiciamteh` | `ci-in kiciamteh hi.` | Is acknowledged for that. |
| 7 | `kiletkhia` | `a kiletkhia ahi hi.` | It was translated. |
| 8 | `kibubawl` | `khat kibubawl hi.` | One was combined-made. |
| 9 | `kiseh` | `etphatna committee kiseh a.` | An editing committee was formed. |
| 10 | `kizawh` | `Thuciam Lui a kizawh huna kipan` | From the time the New Testament was finished |

### Word-by-Word Analysis

```
bu 1,000 kibawl hi.
[bu] [1,000] [ki-bawl] [hi]
[book] [1,000] [REFL-make] [DECL]
"1,000 copies were made."
```

```
India pan khenkik hi.
[India] [pan] [khen-kik] [hi]
[India] [from] [divide-back] [DECL]
"Was reprinted from India."
```

```
Thuciam Lui a kigawm hi.
[Thuciam-Lui] [a] [ki-gawm] [hi]
[New-Testament] [3SG.AGR] [REFL-combine] [DECL]
"New Testament was combined."
```

## 2. Passive + Agent (Ergative)

### Pattern

```
[Agent] + in + [Object] + [ki-Verb] + hi = "[Agent] [verbed] the [object]"
```

When the agent IS mentioned, it takes ergative `in`.

### Examples

| # | Agent | Passive Verb | Full Sentence | Translation |
|---|-------|-------------|---------------|-------------|
| 1 | `BFBS in` | `khenkik` | `BFBS in ABFMS' phalna tawh India pan khenkik hi.` | BFBS, with ABFMS permission, reprinted from India. |
| 2 | `TBA in` | `ap` | `TBA in Lai Siangtho nasepna ZCLS ap hi.` | TBA handed over Bible work to ZCLS. |
| 3 | `Bible Society of Burma in` | `bawl` | `Bible Society of Burma in Late a bu-in bawl hi.` | Bible Society of Burma combined it with Late. |
| 4 | `Cope Topa in` | `zo` | `Cope Topa in 1914 kumin Mate zo hi.` | Rev. Cope completed Matthew in 1914. |
| 5 | `Rev. Vial Nang in` | `huh` | `Rev. Vial Nang in huh hi, ci-in kiciamteh hi.` | Rev. Vial Nang supported it, and is acknowledged. |

### Word-by-Word Analysis

```
BFBS in ABFMS' phalna tawh India pan khenkik hi.
[BFBS] [in] [ABFMS] [phalna-tawh] [India] [pan] [khen-kik] [hi]
[BFBS] [ERG] [ABFMS] [permission-with] [India] [from] [divide-back] [DECL]
"BFBS, with ABFMS permission, reprinted from India."
```

## 3. Passive Verb Inventory

### From the Article

| Verb | Components | Meaning | Passive Example |
|------|------------|---------|-----------------|
| `kibawl` | `ki` (REFL) + `bawl` (make) | was made | `bu 1,000 kibawl hi` |

| `khenkik` | `khen` (divide) + `kik` (back) | was reprinted | `India pan khenkik hi` |
| `kigawm` | `ki` (REFL) + `gawm` (combine) | was combined | `Thuciam Lui a kigawm hi` |
| `kikhensat` | `ki` (REFL) + `khen` (decide) + `sat` (CMPL) | was decided | `khetkik dingin kikhensat hi` |
| `kiciamteh` | `ki` (REFL) + `ciam` (recognize) + `teh` (CMPL) | was acknowledged | `ci-in kiciamteh hi` |
| `kiletkhia` | `ki` (REFL) + `let` (write) + `khia` (out) | was translated | `a kiletkhia ahi hi` |
| `kibubawl` | `ki` (REFL) + `bu` (combine) + `bawl` (make) | was combined-made | `khat kibubawl hi` |
| `kiseh` | `ki` (REFL) + `seh` (form) | was formed | `committee kiseh a` |
| `kizawh` | `ki` (REFL) + `zawh` (finish) | was finished | `Thuciam Lui a kizawh` |

## 4. Passive vs Active Comparison

### When Agent Is Known

| Active | Passive | When Used |
|--------|---------|-----------|
| `BSM in bu 1,000 bawl hi.` | `bu 1,000 kibawl hi.` | Agent known vs unknown |
| `BFBS in suakkhia hi.` | `suakkhia hi.` | Formal vs impersonal |
| `Rev. Kam Khaw Thang in kigawm hi.` | `kigawm hi.` | Personal vs institutional |

### When Agent Is Unknown/Irrelevant

| Passive | Agent | Translation |
|---------|-------|-------------|
| `bu 1,000 kibawl hi` | unknown | 1,000 copies were made |
| `khenkik hi` | BFBS (implied) | Was reprinted |
| `kigawm hi` | committee (implied) | Was combined |
| `kiseh a` | unknown | Was formed |
| `kikhensat hi` | committee (implied) | Was decided |

### Formal vs Informal Usage

| Register | Pattern | Example |
|----------|---------|---------|
| Formal | `kibawl hi` | `bu 1,000 kibawl hi` (impersonal) |
| Formal | `suakkhia hi` | `a laibu-in suakkhia hi` (result focus) |
| Informal | `ki-verb` with `ka` | `ka Ki sap na teng` (my work was done) |

## 5. Passive + Postposition Patterns

### Pattern: `[Passive Verb] + [Postposition]`

| Pattern | Example | Translation |
|---------|---------|-------------|
| `pan + [passive]` | `India pan khenkik hi` | Was reprinted from India |
| `pana + [passive]` | `ABM Press pana kibawl hi` | Was made from ABM Press |
| `ah + [passive]` | `Rangoon ah kibawl` | Was made in Rangoon |
| `tawh + [passive]` | `TBA' vaihawmna tawh... kigawm hi` | Was combined with TBA's management |
| `tung + [passive]` | `BSM tung ah ap na` | Will be handed over to BSM |

### Word-by-Word Analysis

```
ABM Press pana kibawl hi a, 1932 kumin suakkhia zo pan hi.
[ABM-Press] [pana] [ki-bawl] [hi-a] [1932] [kumin] [suakkhia] [zo] [pan] [hi]
[ABM-Press] [from] [REFL-make] [DECL-3SG.AGR] [1932] [year] [print-publish] [complete] [from] [DECL]
"It was made from ABM Press, and was published from 1932."
```

## 8. Key Observations

1. **`ki-` as Passive Marker**: The `ki-` prefix (REFL/reciprocal) functions as a passive marker when the agent is omitted. This is a productive pattern in Zolai.

2. **Result Focus**: Passive constructions focus on the **result** of the action rather than the **doer**. This is typical of formal/historical registers.

3. **Agent Optional**: The agent can be omitted entirely (`bu 1,000 kibawl hi`) or included with ergative `in` (`BFBS in... khenkik hi`).

4. **Postposition Compatibility**: Passive verbs freely combine with postpositions (`pan`, `ah`, `tawh`, `tung`) to express source, location, instrument, and direction.

5. **Register Distribution**: Passive is dominant in formal/historical registers; active voice is more common in informal/personal registers.

6. **Compound Verbs**: Many passive verbs are compounds: `ki-` + verb root + optional suffix (`kibawl`, `kigawm`, `kikhensat`, `kiletkhia`, `kiciamteh`).
