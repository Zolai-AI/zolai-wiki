# ZVS 2018 — Zolai Standard Format

The **Zolai Standard Format (ZVS 2018)** was established by Pa Lian Than Tuang (LT Tuang) on 20 December 2018 to standardize Zolai orthography across all dialects and regions. This document covers the official spelling rules, forbidden forms, and conventions.

---

## 1. Why ZVS 2018 Exists

Zolai uses **Latin phonetic** script, but without a standard format:
- India-based Zomi and Myanmar-based Zomi write differently
- US, UK, Canada, Australia Zomi develop separate conventions
- Zomi from non-English-speaking countries face additional divergence

**Without a standard, Zolai writing will become increasingly fragmented.**

---

## 2. Zolai Vowels

Zolai has **6 vowels**: `a, e, i, o, u, aw`

| Vowel | IPA | Example | Note |
| :--- | :--- | :--- | :--- |
| **a** | /a/ | `tan` | as in "father" |
| **e** | /e/ | `ten` | as in "bet" |
| **i** | /i/ | `tin` | as in "machine" |
| **o** | /oʊ/ | `ton` | as in "go" |
| **u** | /u/ | `tun` | as in "food" |
| **aw** | /ɔː/ | `tawn` | as in "cow" |

### Critical: `o` vs `aw`

These two vowels are frequently confused. Mixing them changes meaning:

| Correct | Incorrect | Meaning Difference |
| :--- | :--- | :--- |
| `toi` | `tawi` | different words |
| `khoi` | `khawi` | different words |
| `khom` | `khawm` | different words |
| `poi` | `pawi` | different words |

**Always check: Is this `o` or `aw`? They are NOT interchangeable.**

## 3. Forbidden Forms (ZVS 2018)

The following **deprecated forms** must be replaced with their ZVS 2018 standard equivalents:

| Deprecated (❌) | Standard (✅) | Meaning |
| :--- | :--- | :--- |
| `pathian` | **`pasian`** | God |
| `ram` | **`gam`** | earth, land |
| `fapa` | **`tapa`** | life |
| `bawipa` | **`topa`** | Lord, master |
| `siangpahrang` | **`kumpipa`** | Holy Spirit |
| `cu` / `cun` | **`tua`** | what, which |
| `suah` | **`chuak`** | come out |
| `zalenna` | **`suahtakna`** | surrender |
| `nunnak` | **`nuntakna`** | joy, happiness |

### Examples

| ❌ Incorrect | ✅ Correct |
| :--- | :--- |
| `Pathian in leitung bawl hi.` | `Pasian in leitung bawl hi.` |
| `Ram ah om hi.` | `Gam ah om hi.` |
| `Bawipa in gen hi.` | `Topa in gen hi.` |
| `Cu hiam?` | `Tua hiam?` |

## 4. Apostrophe (') Rules

The apostrophe indicates **glottal stop** and is used in specific contexts:

### A. Between Vowels (Preventing Hiatus)

| Word | Meaning | Note |
| :--- | :--- | :--- |
| `ko'a` | fight | V'V pattern |
| `va'ah` | beautiful | V'V pattern |
| `ta'a` | stand | V'V pattern |

### B. Possessive Marker (replacing `ii`)

| Pattern | Example | Meaning |
| :--- | :--- | :--- |
| Noun' Noun | `Kote'n Sangpi' mawtaw` | Kote's and Sangpi's car |
| Noun' Noun | `Note'n` | The people's |

### C. Agent Marker (replacing `in`)

| Pattern | Example | Meaning |
| :--- | :--- | :--- |
| Noun'n | `Kote'n` | By Kote |
| Noun'n | `Note'n` | By the people |

### D. Where NOT to Use Apostrophe

- In abbreviations like `Tg.` (Taang) — the dot is sufficient
- In the middle of compound words that are naturally spoken together

## 5. Word Formation Rules

### A. `na` — Noun Formation

| Pattern | Example | Meaning |
| :--- | :--- | :--- |
| Verb + na = Noun | `pai + na = paina` | going (noun) |
| Verb + nading = Infinitive | `pai + nading = painading` | to go |

**Example sentence:** `Ka paina ah nong pai nading kong zawn hi.`

### B. Plural Marker: `te/teng`

| Singular | Plural | Note |
| :--- | :--- | :--- |
| `mi` | `mite` | people |
| `naupang` | `naupangte` | youngsters |
| `noteng` | `notengte` | the people (emphatic) |

**Rule:** `te/teng` must be attached to the noun, not separated.

### C. Adverb Marker: `lua`

| Adjective | Adverb | Note |
| :--- | :--- | :--- |
| `gik` | `giklua` | badly |
| `hoih` | `hoihlua` | well (manner) |

### D. Negative Prefix: `lo/keh/kei`

| Positive | Negative | Note |
| :--- | :--- | :--- |
| `pailoh` | `lo` | don't go |
| `kei` | `kei` | don't (prohibitive) |

### E. Comparative Markers

| Marker | Function | Example |
| :--- | :--- | :--- |
| `zaw` | comparative | `hoihzaw` (better) |
| `sem` | comparative | `hoihsem` (nicer) |
| `pen` | superlative | `hoihpen` (best) |
| `penpen` | absolute | `hoih penpen` (the very best) |

---

## 6. `A` vs `Ki` Prefixes

| Prefix | Function | Example |
| :--- | :--- | :--- |
| **A** + verb | Active/antipassive | `A pai hi.` (He goes.) |
| **Ki** + verb | Causative/reflexive | `Mawtaw kineisak aa kipai hi.` (By car.) |
| **A** + noun | Possessive | `A mawtaw hoih hi.` (His car is good.) |
| **Ki** + noun | Reflexive | `Ki mawtaw neisak.` (He owns a car.) |

---

## 7. `G` vs `Ng` Sounds

Both `g` and `ng` are valid in Zolai. Neither is "more correct":

| Word | Meaning | Note |
| :--- | :--- | :--- |
| `gai` | chicken | `g` initial |
| `ngai` | rags | `ng` initial |
| `gah` | consequence | `g` initial |
| `ngah` | receive | `ng` initial |
| `gam` | earth | `g` initial |
| `ngam` | yield | `ng` initial |

**Note:** Some speakers prefer `g` everywhere, but both are standard in Tedim.

## 8. Pronoun System

### Subject Pronouns

| Person | Singular | Plural |
| :--- | :--- | :--- |
| 1st | `ka` (I) | `ko` (we excl.) / `i` (we incl.) |
| 2nd | `nang` (you) | `nangte` (you all) |
| 3rd | `amah` (he/she) | `amaute` (they) |

### Possessive Pronouns

| Person | Singular | Plural |
| :--- | :--- | :--- |
| 1st | `ka` (my) | `ko` (our excl.) / `i` (our incl.) |
| 2nd | `na` (your) | `naute` (your all) |
| 3rd | `a` (his/her) | `amau` (their) |

---

## 9. Punctuation Rules

| Mark | Usage | Example |
| :--- | :--- | :--- |
| `.` | Sentence end | `Ka pai hi.` |
| `?` | Question | `Na pai hiam?` |
| `!` | Exclamation | `Haa! thadah ta ei.` |
| `,` | Clause separation | `Tua ciangin, ka pai hi.` |
| `:` | Enumeration | `Kammal: pai, sem, gen` |
| `;` | Complex list | `Pai; sem; gen` |
| `—` | Dash | `Tua — ka pai hi.` |
| `'` | Glottal stop | `ko'a` |

## 10. Abbreviation Rules

| Abbreviation | Full Form |
| :--- | :--- |
| `gtn.` | gentehna (example) |
| `adt.` | adangte (others) |
| `cbd.` | cihbangdan (etc.) |
| `ahk.` | ahihkeh (but) |
| `akl.` | aihkei leh (and/or) |
| `Tg.` | Taang (title) |
| `Las.` | Lasa, La siam |

**Rule:** Abbreviations require a dot: `Tg.` ✅ not `Tg` ❌
