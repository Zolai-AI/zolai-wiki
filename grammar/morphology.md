# Zolai Morphology — Word Formation Patterns
> Last updated: 2026-09-10

Word formation in Zolai (Tedim) follows systematic patterns documented in *Zolai Gelhmaan Vol. 1* (Taang Zomi, 2010). The language uses suffixes, prefixes, reduplication, and compounding to build vocabulary from root forms.

---

## 1. Noun Formation (Noun Pian'sakna)

### A. Verb → Noun (Agent/Doer)

| Pattern | Example | Meaning |
| :--- | :--- | :--- |
| **Verb + -na** | `tua` (teach) → `tuana` | teacher |
| **Verb + -na** | `nek` (eat) → `nekna` | eater |
| **Verb + -na** | `gen` (speak) → `genna` | speech, speaker |
| **Verb + -na** | `ci` (say) → `cina` | speech, saying |

### B. Verb → Abstract Noun

| Pattern | Example | Meaning |
| :--- | :--- | :--- |
| **Verb + -hna** | `gam` → `gamhna` | creation |
| **Verb + -hna** | `tua` → `tuahna` | teaching |
| **Verb + -hna** | `piang` → `pianghna` | birth |
| **Verb + -hna** | `sih` → `sihna` | death |

### C. Verb → Result Noun

| Pattern | Example | Meaning |
| :--- | :--- | :--- |
| **Verb + -sak** | `piang` → `piangsak` | created thing |
| **Verb + -sak** | `bawl` → `bawlsak` | formation |
| **Verb + -sak** | `suak` → `suaksak` | creation, thing made |

### D. Infinitive / Verbal Noun

| Pattern | Example | Meaning |
| :--- | :--- | :--- |
| **Verb + -nading** | `tua` → `tuanading` | to teach |
| **Verb + -nading** | `nek` → `neknading` | to eat |
| **Verb + -nading** | `pai` → `painading` | to go |

## 2. Causative & Antipassive

### A. Causative (ki- prefix)

| Pattern | Example | Meaning |
| :--- | :--- | :--- |
| **ki- + Verb** | `tua` → `kitua` | cause to teach |
| **ki- + Verb** | `nek` → `kinek` | cause to eat |
| **ki- + Verb** | `pai` → `kipai` | cause to go (by vehicle) |

### B. Antipassive (a- prefix)

| Pattern | Example | Meaning |
| :--- | :--- | :--- |
| **a- + Verb** | `tua` → `atua` | teach (intransitive) |
| **a- + Verb** | `nek` → `anek` | eat (intransitive) |

## 3. Comparative & Superlative

| Pattern | Example | Meaning |
| :--- | :--- | :--- |
| **ADJ + kia** | `hun kia` | bigger |
| **ADJ + kia + NP** | `hun kia mi` | bigger than me |
| **ADJ + kia + ti** | `hun kia ti` | biggest |

Additional comparative markers from ZVS 2018:

| Marker | Function | Example |
| :--- | :--- | :--- |
| **zaw** | comparative | `hoihzaw` (better) |
| **sem** | comparative | `hoihsem` (nicer) |
| **pen** | superlative | `hoihpen` (best) |
| **penpen** | absolute superlative | `hoih penpen` (the very best) |

## 4. Pluralization

| Pattern | Example | Meaning |
| :--- | :--- | :--- |
| **Noun + te** | `mi` → `mite` | people, persons |
| **Noun + te** | `tanu` → `tanute` | daughters |
| **Noun + teng** | `naupang` → `naupangte` | youngsters (emphatic plural) |

Note: `te/teng` are also used as function words depending on position:
- **Plural noun marker:** `mite` (people)
- **Adverbial marker:** (rare, context-dependent)

## 5. Reduplication (Kilanghsak Kammalte)

Zolai uses reduplication for emphasis, plurality, and intensity.

### Full Reduplication

| Base | Reduplicated | Meaning |
| :--- | :--- | :--- |
| `dang` | `dangdang` | slowly |
| `mem` | `memmam` | softly |
| `geel` | `geelgaal` | teach (emphatic) |
| `lem` | `lemlem` | dimly |
| `saisai` | `saisaisai` | quietly |

### Partial Reduplication

| Base | Reduplicated | Meaning |
| :--- | :--- | :--- |
| `mel` | `melmal` | softly |
| `meu` | `meumau` | gently |
| `vei` | `veivai` | various |
| `zi` | `zipzup` | quickly |
| `kek` | `kekkok` | repeatedly |

### Common Reduplication Patterns

- **AABB pattern:** `dangdang`, `memmam`, `lemlem` — emphatic/continuous
- **ABAB pattern:** `zalzual`, `zipzup`, `zekzawk` — varied/intensive
- **ABB pattern:** `kelkai`, `kiahkuah` — comparison/variety

## 6. Compounding (Lai-mal-kawn)

Zolai forms compound words by combining two or more roots.

| Compound | Components | Meaning |
| :--- | :--- | :--- |
| `vantung` | `van` + `tung` | heaven/sky |
| `tungah` | `tung` + `ah` | above, on top of |
| `innkuan` | `inn` + `kuan` | family, household |
| `khutsung` | `khut` + `sung` | hand (lit. hand-inside) |
| `mawtaw` | `maw` + `taw` | car/vehicle |
| `laibu` | `lai` + `bu` | book (lit. letter-container) |
| `biakinn` | `biak` + `inn` | house (lit. worship-house) |
| `khuapi` | `khua` + `pi` | town |
| `lampi` | `lam` + `pi` | road, path |
| `singkuang` | `sing` + `kuang` | neck |

### Common Compound Patterns

| Pattern | Example | Meaning |
| :--- | :--- | :--- |
| N + N | `khuapi` (town) | compound noun |
| N + V | `biakinn` (church) | noun + noun |
| V + N | `laibu` (book) | verb + noun |
| Adj + N | `vantung` (heaven) | adjective + noun |

## 7. Derivational Suffixes Summary

| Suffix | Function | Example |
| :--- | :--- | :--- |
| **-na** | Agent/doer noun | `tuana` (teacher) |
| **-hna** | Abstract noun | `tuahna` (teaching) |
| **-sak** | Result noun | `piangsak` (creation) |
| **-nading** | Infinitive | `tuanading` (to teach) |
| **-na** (V→N) | Action noun | `genna` (speech) |
| **-in** | Past tense marker | `takin` (truly) |
| **-te** | Plural marker | `mite` (people) |
| **-ah** | Locative/directional | `vantungah` (in heaven) |

## 8. Particle Functions

Zolai particles (minna) serve multiple grammatical roles depending on context:

| Particle | Primary Function | Example |
| :--- | :--- | :--- |
| **hi** | copula / declarative | `Amah pasal hi.` (He is a man.) |
| **in** | ergative marker / imperative | `Amah in nek hi.` (He eats.) |
| **pen** | topic marker | `Amah pen pasal hi.` (As for him, he is a man.) |
| **hiam** | question marker | `Na pai hiam?` (Will you go?) |
| **ding** | future tense | `Ka pai ding.` (I will go.) |
| **leh** | and / with | `Kei leh nang` (You and I) |
| **ah** | but / however | `Ka deih ah ka theilo.` (I want but I can't.) |
| **tua** | that (demonstrative) | `Tua mi pen pasal hi.` (That man is good.) |
| **hih** | this (demonstrative) | `Hih mi pen pasal hi.` (This man is good.) |
