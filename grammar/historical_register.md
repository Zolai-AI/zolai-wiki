# Historical Register — Formal Narrative Patterns

> Reference for formal historical narrative patterns in Zolai, drawn from "Tedim Lai Siangtho Tangthu Tom."
> Source: zolai-wiki/grammar/article_analysis_tangthu.md

---

## Overview

The historical register in Zolai is characterized by:
- **Passive/impersonal voice** (agent often omitted)
- **Systematic date constructions** (year + postposition)
- **Organizational agents** with ergative `in`
- **Formal connectives** (Tua ciangin, Tua khit, Ahih manin)
- **Technical publishing vocabulary**
- **Long, complex sentences** with multiple clauses

---

## 1. Date Constructions

### Core Pattern: `[number] + kumin`

| Pattern | Example | Translation | Function |
|---------|---------|-------------|----------|
| `[year] kumin` | `1914 kumin Mate zo hi` | In 1914, Matthew was completed | Simple date |
| `[year] kum ciangin` | `1967 kum ciangin` | After 1967 | Temporal (after) |
| `[year] kum panin` | `1972 kum panin` | From 1972 | Temporal (from) |
| `[year] kuma` | `1960 kuma kipan` | Beginning in 1960 | Temporal (that year) |
| `[year] leh [year] kumin` | `1948 leh 1951 kumin zong` | In 1948 and 1951 also | Multiple dates |
| `[year] kuma kibawl` | `1967 kuma kibawl pen mah` | The very one made in 1967 | Emphatic reference |

### Word-by-Word Analysis

```
1914 kumin Mate zo hi.
[1914] [kumin] [Mate] [zo] [hi]
[year] [year-POST] [Matthew] [complete] [DECL]
"In 1914, Matthew was completed."
```

```
1967 kum ciangin Bible Society of Burma in...
[1967] [kum] [ciangin] [Bible-Society-of-Burma] [in]...
[year] [year] [after] [Bible-Society-of-Burma] [ERG]...
"After 1967, Bible Society of Burma..."
```

### Date + Postposition Combinations

| Postposition | Meaning | Example |
|--------------|---------|---------|
| `kumin` | in (year) | `1914 kumin` — in 1914 |
| `kum ciangin` | after (year) | `1967 kum ciangin` — after 1967 |
| `kum panin` | from (year) | `1972 kum panin` — from 1972 |
| `kuma` | (year)-that | `1960 kuma` — in that year 1960 |
| `kum ah` | at (year) | (not in article, but valid) |

## 2. Passive Constructions

### Pattern: `[agent omitted] + verb + hi`

The historical register extensively uses passive voice, especially when the agent is unknown, irrelevant, or an organization.

| Verb | Example | Translation | Agent |
|------|---------|-------------|-------|
| `kibawl` | `bu 1,000 kibawl hi` | 1,000 copies were made | unknown |
| `suakkhia` | `a laibu-in suakkhia hi` | it was printed as a book | unknown |
| `khenkik` | `India pan khenkik hi` | was reprinted from India | BFBS (implied) |
| `kigawm` | `Thuciam Lui a kigawm hi` | New Testament was combined | unknown |
| `kikhensat` | `khetkik dingin kikhensat hi` | it was decided to reprint | committee |
| `kiciamteh` | `ci-in kiciamteh hi` | is acknowledged for that | community |
| `kiletkhia` | `a kiletkhia ahi hi` | it was translated | translators |
| `kibubawl` | `khat kibubawl hi` | one was combined-made | BSM + ZCLS |
| `kiseh` | `etphatna committee kiseh a` | an editing committee was formed | unknown |
| `kigawm` | `a kigawm Lai Siangtho` | was combined into a Bible | unknown |

### Word-by-Word: Passive Analysis

```
bu 1,000 kibawl hi.
[bu] [1,000] [ki-bawl] [hi]
[book] [1,000] [REFL-make] [DECL]
"1,000 copies were made."
```

```
India pan khenkik hi.
[India] [pan] [khen-kik] [hi]
[India] [from] [divide-back] [DECL]
"Was reprinted from India."
```

### Passive + Agent (Ergative)

When the agent IS mentioned, it takes ergative `in`:

| Example | Agent | Pattern |
|---------|-------|---------|
| `BFBS in... khenkik hi` | BFBS | S-ERG + O + V-passive |
| `TBA in... ZCLS ap hi` | TBA | S-ERG + O + V-passive |
| `Bible Society of Burma in... bawl hi` | BSofBurma | S-ERG + O + V-passive |
| `Cope Topa in... zo hi` | Cope Topa | S-ERG + O + V-completive |

### Passive vs Active Comparison

| Passive (historical) | Active (hypothetical) | When Used |
|----------------------|----------------------|-----------|
| `bu 1,000 kibawl hi` | `BSM in bu 1,000 bawl hi` | Agent unknown/irrelevant |
| `suakkhia hi` | `BFBS in suakkhia hi` | Focus on result |
| `khenkik hi` | `ABFMS in khenkik hi` | Formal/historical style |
| `kigawm hi` | `Rev. Kam Khaw Thang in kigawm hi` | Impersonal style |

## 3. Organizational Agent Patterns

### Pattern: `[Organization] + in + [action]`

Organizations are treated as agents with ergative `in`:

| Organization | Example | Translation |
|-------------|---------|-------------|
| `BFBS in` | `BFBS in ABFMS' phalna tawh India pan khenkik hi` | BFBS, with ABFMS permission, reprinted from India |
| `TBA in` | `TBA in Lai Siangtho nasepna ZCLS ap hi` | TBA handed over Bible work to ZCLS |
| `Bible Society of Burma in` | `Bible Society of Burma in Late a bu-in bawl hi` | Bible Society of Burma combined it with Late |
| `ZCLS' vaihawmna tawh` | `ZCLS' vaihawmna tawh Rev. Kam Khaw Thang mah in` | With ZCLS's management, Rev. Kam Khaw Thang himself... |
| `BSM in` | `BSM in... khenkik hi` | BSM reprinted |

### Organization + Postposition Patterns

| Pattern | Example | Meaning |
|---------|---------|---------|
| `[Org] + in + [verb]` | `BFBS in khenkik hi` | BFBS reprinted (ergative) |
| `[Org] + vaihawmna + tawh` | `TBA' vaihawmna tawh` | With TBA's management |
| `[Org] + pan + [verb]` | `ABM Press pana kibawl hi` | Made from ABM Press |
| `[Org] + tung + ah` | `Bible Society Myanmar tung ah` | On/to Bible Society Myanmar |
| `[Org] + kiang + ah` | `Bible Society Myanmar kiang ah` | Toward Bible Society Myanmar |
| `[Org] + phalna + tawh` | `ABFMS' phalna tawh` | With ABFMS's permission |

## 4. Formal Connectives

| Connector | Meaning | Example | Function |
|-----------|---------|---------|----------|
| `Tua ciangin` | After that/Then | `Tua ciangin Rev. Khup Za Go...` | Temporal sequence |
| `Tua khit` | After that | `Tua khit, 2005 kumin...` | Temporal sequence |
| `Tua hangin` | Moreover | `Tua hangin kammal bul...` | Addition |
| `Tua bangin` | Like that | `Tua bangin a kihanciam ciangin` | Manner comparison |
| `Ahih manin` | Because | `kingaklah lua ta ahih manin` | Causal |
| `Ahi zongin` | Also | `Ahi zongin Lai Siangtho sunga...` | Addition |
| `Nasep zomsuak a` | While work was completed | `Nasep zomsuak a, 1929 kumin...` | Temporal (while) |
| `Tua leh` | So/then | `Tua leh, Tedim Lai Siangtho...` | Consequence |
| `Tua manin` | Therefore | (implied in transitions) | Causal |
| `A masa in` | At first | `A masa in, Ken official letter...` | Temporal (initial) |

### Word-by-Word: Connective Analysis

```
Tua ciangin Rev. Khup Za Go leh Rev. G. K. Nang...
[Tua] [ciangin] [Rev. Khup Za Go] [leh] [Rev. G. K. Nang]...
[that] [after] [Rev. Khup Za Go] [and] [Rev. G. K. Nang]...
"After that, Rev. Khup Za Go and Rev. G. K. Nang..."
```

## 6. Sentence Templates (Historical)

| Template | Example | Translation |
|----------|---------|-------------|
| `[Year] kumin [Agent] in [Object] [Verb] hi.` | `1914 kumin Cope Topa in Mate zo hi.` | In 1914, Rev. Cope completed Matthew. |
| `[Year] kumin [Object] [Passive-Verb] hi.` | `1929 kumin Thuciam Thak bup zo hi.` | The Old Testament was combined in 1929. |
| `[Org] in [Object] [Verb] hi.` | `BFBS in... khenkik hi.` | BFBS reprinted it. |
| `[Org]' vaihawmna tawh [Person] in [Object] [Verb] hi.` | `TBA' vaihawmna tawh... bup neih masakna ahi hi.` | With TBA's management, this was the first time... |
| `Tua [Noun] pen [Description] ahi hi.` | `Tua Thuciam Thak pen... ahi hi.` | That Old Testament was... |
| `[Year] kum ciangin [Agent] in [Object] [Verb] hi.` | `1967 kum ciangin Bible Society of Burma in...` | After 1967, Bible Society of Burma... |
