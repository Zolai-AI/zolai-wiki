# Zolai Syntax — Sentence Structure
> Last updated: 2026-09-10

Zolai (Tedim) follows **SOV (Subject-Object-Verb)** word order as its basic syntactic pattern. This document covers clause structure, subordination, coordination, relative clauses, and question formation.

---

## 1. Basic Word Order: SOV

The fundamental sentence structure is **Subject + Object + Verb**.

### Examples

| English | Zolai | Structure |
| :--- | :--- | :--- |
| God created the world. | Pasian leitung bawl hi. | S + O + V |
| I eat rice. | Ka ne hi. | S + O + V |
| He reads the book. | Amah laibu sim hi. | S + O + V |
| The man went to the village. | Mipa khua ah pai hi. | S + Loc + V |

### Subject Marking

The ergative marker **in** marks the agent/subject of transitive verbs:

| Sentence | Meaning |
| :--- | :--- |
| `Amah in laibu sim hi.` | He reads the book. (emphatic subject) |
| `Mipa in ne hi.` | The man eats rice. |
| `Pasian in leitung bawl hi.` | God created the world. |

Note: **in** is optional in many contexts but required for emphasis or clarity.

## 2. Clause Structure

### A. Simple Clauses

| Pattern | Example | Meaning |
| :--- | :--- | :--- |
| S + V | `Ka pai hi.` | I go. |
| S + O + V | `Ka ne hi.` | I eat rice. |
| S + IO + DO + V | `Ka amah ah an pi hi.` | I give him rice. |

### B. Copular Sentences

| Pattern | Example | Meaning |
| :--- | :--- | :--- |
| S + pen + NP + hi | `Amah pen pasal hi.` | He is a man. |
| S + pen + ADJ + hi | `Tua pen hoih hi.` | That is good. |
| S + ahi hi | `Amah ahi hi.` | He is (emphatic). |

### C. Existential Sentences

| Pattern | Example | Meaning |
| :--- | :--- | :--- |
| S + om hi | `Amah om hi.` | He exists/is present. |
| S + omlo hi | `Amah omlo hi.` | He doesn't exist. |

## 3. Coordination (Kammal Zom)

### A. Conjunctions

| Conjunction | Meaning | Example |
| :--- | :--- | :--- |
| **leh** | and | `Kei leh nang` (You and I) |
| **ah** | but | `Ka deih ah ka theilo.` (I want but I can't.) |
| **na** | or | `Tua na hih` (That or this) |
| **cih** | because | `Cih hangin ka pai hi.` (Because of that, I go.) |

### B. Coordination Patterns

| Pattern | Example | Meaning |
| :--- | :--- | :--- |
| NP leh NP | `Kei leh nang` | You and I |
| Clause leh Clause | `Ka pai hi leh ka sim hi.` | I go and I read. |
| Clause cih Clause | `Ka thei cih ka gen hi.` | Because I know, I say. |
| Clause ah Clause | `Ka deih ah ka theilo.` | I want but I can't. |

---

## 4. Subordination

### A. Temporal Clauses

| Marker | Function | Example |
| :--- | :--- | :--- |
| **ciangin** | when/then | `Tua ciangin ka pai hi.` (Then I went.) |
| **matengin** | until | `Zing tak matengin ka sem hi.` (I work until morning.) |
| **laitakin** | while | `Pai laitakin ka gen hi.` (While going, I speak.) |

### B. Causal Clauses

| Marker | Function | Example |
| :--- | :--- | :--- |
| **hangin** | because | `Cih hangin ka pai hi.` (Because of that, I go.) |
| **manin** | since | `Cih manin ka pai hi.` (Since that, I go.) |
| **panin** | due to | `Cih panin ka pai hi.` (Due to that, I go.) |

### C. Conditional Clauses

| Marker | Function | Example |
| :--- | :--- | :--- |
| **leh** | if | `Na pai leh ka pai ding.` (If you go, I will go.) |
| **inla** | when/if | `Pai inla va gen in.` (When going, tell them.) |

### D. Purpose Clauses

| Marker | Function | Example |
| :--- | :--- | :--- |
| **nading** | in order to | `Tua nading ka pai hi.` (I go for that purpose.) |
| **ading** | for (benefactive) | `Pasian ading ka sem hi.` (I work for God.) |

---

## 5. Relative Clauses

Zolai uses pre-nominal relative clauses:

| Pattern | Example | Meaning |
| :--- | :--- | :--- |
| Clause + Noun | `Ka gen thu pen hoih hi.` | The word I say is good. |
| Clause + Noun | `Amah sim laibu pen hoih hi.` | The book he reads is good. |

### Relative Clause Markers

| Marker | Function | Example |
| :--- | :--- | :--- |
| **cihna** | that which | `Cihna ka gen pen dik hi.` (What I say is true.) |
| **bangin** | as/like | `Bangin ka gen ciangin ka gen hi.` (As I say, I say.) |

## 6. Question Formation (Hiam)

**Hiam is the universal question marker in Zolai** — used for both yes/no questions and content questions.

### A. Yes/No Questions

| Pattern | Example | Meaning |
| :--- | :--- | :--- |
| Statement + hiam | `Na pai hiam?` | Will you go? |
| Statement + hiam | `Amah om hiam?` | Is he present? |
| Statement + hiam | `Na thei hiam?` | Do you know? |

### B. Content Questions

| Question Word | Meaning | Example |
| :--- | :--- | :--- |
| **bang** | what | `Na sep bang hiam?` (What are you doing?) |
| **bangci** | how | `Na pai bangci hiam?` (How do you go?) |
| **kua** | who | `Kua hiam?` (Who is it?) |
| **kuan** | whom | `Kuan na mu hiam?` (Whom did you see?) |
| **mun** | where | `Na pai mun hiam?` (Where do you go?) |
| **zun** | when | `Na pai zun hiam?` (When do you go?) |
| **tua** | which/what | `Tua hiam?` (Which one?) |
| **cihna** | why | `Cihna hiam?` (Why?) |

### C. Tag Questions

| Pattern | Example | Meaning |
| :--- | :--- | :--- |
| Statement + maw | `Na pai maw?` (Aren't you going?) |
| Statement + dia | `Na pai dia?` (Will you go?) |

### D. Question Markers Comparison

| Marker | Usage | Register |
| :--- | :--- | :--- |
| **hiam** | Universal (yes/no + content) | Standard/Official |
| **dia** | Casual yes/no | Informal |
| **maw** | Tag question | Informal |
| **hai** | Casual question | Colloquial |

## 7. Negation

| Marker | Function | Example |
| :--- | :--- | :--- |
| **kei** | General negation (1st/2nd person) | `Ka pai kei hi.` (I don't go.) |
| **lo** | General negation (3rd person) | `Amah pai lo hi.` (He doesn't go.) |
| **si** | verb (die/dead) | `Khazih a si hi.` (Christ died.) |
| **ken** | Strong prohibitive | `Pai ken.` (Do not go!) |
| **neilo** | Have not | `Ka nei lo.` (I don't have.) |

### Negative Constructions

| Affirmative | Negative | Meaning |
| :--- | :--- | :--- |
| `Ka pai hi.` | `Ka pai kei hi.` | I don't go. |
| `Na pai hi.` | `Na pai kei hi.` | You don't go. |
| `Amah pai hi.` | `Amah pai lo hi.` | He doesn't go. |
| `Amah om hi.` | `Amah omlo hi.` | He isn't here. |
| `Ka thei hi.` | `Ka theilo hi.` | I don't know. |
| `Ka nei hi.` | `Ka neilo hi.` | I don't have. |

---

## 8. Serial Verb Constructions

Zolai commonly chains verbs without conjunctions:

| Pattern | Example | Meaning |
| :--- | :--- | :--- |
| V + V | `Ka tai sim hi.` | I sit and read. |
| V + V | `Amah ta pai hi.` | He stands up and goes. |
| V + V | `Amah nek zo.` | He finished eating. |

---

## 9. Tense & Aspect Markers

| Marker | Function | Example |
| :--- | :--- | :--- |
| **hi** | Present/default | `Ka pai hi.` (I go.) |
| **ta** | Inceptive (just happened) | `Ka pai ta.` (I just went.) |
| **takin** | Perfective | `Ka pai takin.` (I have gone.) |
| **lai** | Progressive | `Ka pai lai hi.` (I am going.) |
| **ding** | Future | `Ka pai ding.` (I will go.) |
| **khin** | Experiential | `Ka pai khin.` (I have gone before.) |
| **zo** | Completive | `Ka pai zo.` (I have finished going.) |
