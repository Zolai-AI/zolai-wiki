# Complete Zolai Phonology Reference

## Overview

This document provides a comprehensive phonological analysis of Zolai (Tedim), including full consonant and vowel inventories with IPA, tone system, syllable structure, phonotactic constraints, loan word adaptation, sound changes in compounds, and minimal pairs. All examples use correct ZVS 2018 orthography.

## 3. Tone System

### 3.1. Tone Inventory

Zolai has a complex tonal system. While not always marked in standard orthography, tones are phonemic:

| Tone | Name | Contour | Examples | Notes |
|------|------|---------|----------|-------|
| **Tone I** | Flat/Level | High level (55) | `Phei2pai` | Most common |
| **Tone II** | Falling | High falling (53) | `Nuaikiat` | Common |
| **Tone III** | Rising | Low rising (13) | `Tanglak` | Less common |
| **Tone IV** | Dipping | Low dipping (214) | `Zatzia` | Rare |

### 3.2. Tone Marking

- Standard orthography does **not** mark tones
- Double vowels can indicate long tones: `vaan` (sky) vs `van` (goods)
- Context determines tone in most cases
- Regional dialects may have different tone patterns

## 4. Syllable Structure

### 4.1. Basic Syllable Patterns

| Pattern | Example | Structure | Notes |
|---------|---------|-----------|-------|
| **V** | `a` (that) | Vowel only | Rare |
| **CV** | `pa` (father) | Consonant + Vowel | Most common |
| **CVC** | `pat` (open) | Consonant + Vowel + Consonant | Common |
| **CVV** | `pai` (go) | Consonant + Vowel + Vowel | Common (diphthongs) |
| **CVVC** | `pait` (went) | Consonant + Vowel + Vowel + Consonant | Common |
| **CCV** | `khua` (village) | Cluster + Vowel | Common (4 clusters) |
| **CCVC** | `khuat` (cut) | Cluster + Vowel + Consonant | Common |

### 4.2. Syllable Constraints

1. **No initial consonant clusters except**: `kh`, `ph`, `ng`, `th`
2. **No final consonant clusters**: Only one final consonant allowed
3. **No /t/ + /i/ combination**: `t` never precedes `i` in native words
4. **No /c/ + /a, e, o, aw/ combination**: `c` only pairs with `i` and `u`
5. **No /uh/ with first-person /i/**: `I pai hi` ✅ vs `I pai-te hi` ❌

## 5. Phonotactic Constraints

### 5.1. Forbidden Combinations

Based on *Zolai Sinna Bu* (lines 1074–1076):

| Constraint | Rule | Example | Notes |
|------------|------|---------|-------|
| **[t] + [i]** | Never combine | `tui` ✅ vs `ti` ❌ | Use different vowel |
| **[c] + [a, e, o, aw]** | Never combine | `ci` ✅ vs `ca` ❌ | Only `i` and `u` allowed |
| **[uh] + first-person [i]** | Never combine | `I pai hi` ✅ | Plural marker restriction |

### 5.2. Nasal `h` Distinction

Final `h` changes meaning:

| Word | Without `h` | With `h` | Notes |
|------|-------------|----------|-------|
| `zang` | use | `zangh`: bad quality | Semantic shift |
| `lang` | appear | `langh`: reveal openly | Semantic shift |
| `cing` | precise/skilled | `cingh`: very precise | Intensification |
| `zong` | also/search | `zongh`: also (emphatic) | Emphasis |
| `dong` | request | `dongh`: arrive/block | Semantic shift |

### 5.3. Vowel Restrictions

| Vowel | Allowed Positions | Notes |
|-------|-------------------|-------|
| **a** | Initial, medial, final | Most common |
| **e** | Initial, medial, final | Common |
| **i** | Initial, medial, final | Common (but not after `t`) |
| **o** | Initial, medial, final | Often diphthongized |
| **u** | Initial, medial, final | Common |
| **aw** | Initial, medial, final | Long vowel |

### 6.4. Adaptation Rules

1. **Final consonants may be dropped**: `school` → `sikuul`
2. **Consonant clusters may be simplified**: `street` → `sitiit`
3. **Vowels adjust to Zolai patterns**: `computer` → `komputa`
4. **Plural marker `te` NOT added to borrowed nouns**: `computerte` ❌
5. **Native equivalents preferred**: `book` → `lai-bu` (not `buku`)
