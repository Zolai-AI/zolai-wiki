## 1. Verb Morphology

### 1.1 Verb Roots

Zolai verbs are monosyllabic roots that carry core meaning. The root takes affixes to express direction, aspect, mood, and transitivity.

| Root | Meaning | Stem I | Stem II | Stem II Use |
|------|---------|--------|---------|-------------|
| `pai` | go | `pai` | `piah` | conditional/negation: `Na piah leh...` |
| `gen` | speak | `gen` | `gent` | subordinate: `...gent ciangin` |
| `mu` | see | `mu` | `muh` | subordinate: `...muh leh` |
| `si` | die | `si` | `sih` | nominalization: `sihna` |
| `la` | take | `la` | `laak` | nominalization: `laakna` |
| `sa` | hot | `sa` | `sat` | nominalization: `satna` |
| `nei` | have | `nei` | `neih` | nominalization: `neihna` |
| `thei` | know | `thei` | `theih` | nominalization: `theihna` |
| `sal` | shout | `sal` | `salh` | nominalization: `salhna` |
| `hau` | rich | `hau` | `hauh` | nominalization: `hauhna` |
| `hak` | hard | `hak` | `hah` | nominalization: `hahna` |
| `kap` | cry | `kap` | `kah` | nominalization: `kahna` |
| `that` | kill | `that` | `thah` | nominalization: `thahna` |
| `sam` | call/name | `sam` | `sap` | nominalization: `sapna` |
| `kipan` | start | `kipan` | `kipat` | nominalization: `kipatna` |
| `taang` | transfer | `taang` | `tat` | nominalization: `tatna` |
| `ciah` | return | `ciah` | `ciahk` | subordinate |

**Stem II formation rules (from morphology.md and morphemics.md):**

| Final Sound | Shift | Example |
|-------------|-------|---------|
| Vowel | → -h | `si` → `sih` |
| Vowel | → -k | `la` → `laak` |
| Vowel | → -t | `sa` → `sat` |
| -i | → -ih | `nei` → `neih` |
| -l | → -lh | `sal` → `salh` |
| -u | → -uh | `hau` → `hauh` |
| -k | → -h | `hak` → `hah` |
| -p | → -h | `kap` → `kah` |
| -t | → -h | `that` → `thah` |
| -m | → -p | `sam` → `sap` |
| -n | → -t | `kipan` → `kipat` |
| -ng | → -n' | `thang` → `than'` |
| -ng | → -t | `taang` → `tat` |

### 1.2 Directional Prefixes

Directional prefixes attach to verb roots to indicate the direction of movement relative to the speaker.

| Prefix | Direction | Example | Meaning |
|--------|-----------|---------|---------|
| `hong-` | toward speaker (coming) | `hong pai` | come (lit. "go-toward") |
| `va-` | away from speaker (going) | `va pai` | go there |
| `khia-` | outward | `khia pai` | go out |
| `lut-` | inward | `lut pai` | go in / enter |
| `kik-` | return / back | `kik pai` | go back |
| `toh-` | upward | `toh pai` | go up |
| `suk-` | downward | `suk pai` | go down |

**Examples from zomidaily corpus:**
- `hong om hi.` — He/she came. (lit. "came-toward")
- `va pai hi.` — He/she went (away).
- `khia suak hi.` — Came out / escaped.
- `lut khin hi.` — Entered.
- `kik ciah hi.` — Returned (back).
- `toh kaht hi.` — Climbed up.
- `suk tuih hi.` — Went down / descended.

### 1.3 Aspect Suffixes

Aspect markers follow the verb root (and any directional prefix) to indicate temporal relationship.

| Suffix | Aspect | Example | Meaning |
|--------|--------|---------|---------|
| `-ta` / `ta` | past | `pai ta hi` | went |
| `-ding` / `ding` | future | `pai ding hi` | will go |
| `-zo` / `zo` | completive | `pai zo hi` | finished going |
| `-lai` / `lai` | progressive | `ne lai hi` | is eating |
| `-khin` / `khin` | experiential | `mu khin hi` | have seen (before) |

**Examples from zomidaily:**
- `ka pai ta hi.` — I went.
- `a pai ding hi.` — He will go.
- `ka pai zo hi.` — I have finished going.
- `a ne lai hi.` — He is eating.
- `ka mu khin hi.` — I have seen (before).

### 1.4 Mood Particles

| Particle | Mood | Example | Meaning |
|----------|------|---------|---------|
| `hi` | declarative | `Ka pai hi.` | I go. |
| `hiam` | yes/no question | `Na pai hiam?` | Do you go? |
| `diam` | rhetorical question | `Na lung kim diam?` | Don't you have a heart? |
| `hen` | jussive (let/may) | `Om ta hen.` | Let there be. |
| `in` | imperative (command) | `Pai in.` | Go! |
| `ve` | informal declarative | `Ka pai ve.` | I'm going. (casual) |
| `maw` | tag question | `Hoih maw?` | Good, right? |

### 1.5 Causative (`ki-` prefix)

The `ki-` prefix creates reciprocal, reflexive, or passive forms.

| Pattern | Example | Meaning |
|---------|---------|---------|
| `ki-` + verb | `kitua` | teach each other |
| `ki-` + verb | `kinek` | eat together |
| `ki-` + verb | `kibawl` | be made / created |
| `ki-` + verb | `kipia` | be given / offered |
| `ki-` + verb | `kisia` | be bad / wronged |
| `ki-` + verb | `kigawm` | combine / gather |
| `ki-` + verb | `kikhop` | gather (together) |
| `ki-` + verb | `kipawl` | associate |
| `ki-` + verb | `kilem` | be tested |
| `ki-` + verb | `kitawng` | speak to each other |

**Nominalized forms (ki- + verb + -na):**
- `kipawlna` — organization
- `kisiatna` — evil / wrongdoing
- `kisilna` — bathing
- `kipuahna` — covering
- `kitotna` — competition

### 2.2 Pluralization

| Pattern | Example | Meaning |
|---------|---------|---------|
| `N + te` | `mi` → `mite` | people |
| `N + te` | `tanu` → `tanute` | daughters |
| `N + te` | `naupang` → `naupangte` | youngsters |
| `N + teng` | `naupang` → `naupangte` | all youngsters (emphatic) |
| `N + teng` | `khempeuh teng` | all of everything |

### 2.3 Loan Word Adaptation

Zolai adapts loan words through phonological integration and compounding.

| Loan Word | Zolai Adaptation | Source | Adaptation Rule |
|-----------|------------------|--------|-----------------|
| `Malaysia` | `malaysia` | Malay | Direct borrow (proper noun) |
| `doctor` | `siavuanpa` | — | Descriptive: `si` (heal) + `vuanpa` (person) |
| `copyright` | `copyright` | English | Direct borrow |
| `vitamin` | `vitamin` | English | Direct borrow |
| `hospital` | `zato inn` | English | Compound: `zato` (heal) + `inn` (house) |
| `government` | `kumpi` | — | Native: `kum` (time) + `pi` (great) |
| `election` | `thudik` | — | Descriptive: `thu` (matter) + `dik` (true/right) |
| `passport` | `passport` | English | Direct borrow |
| `Facebook` | `Facebook` | English | Direct borrow |
| `COVID` | `covid` | English | Direct borrow |

**Adaptation patterns:**
1. **Direct borrow:** Most proper nouns and modern technical terms (Malaysia, USA, COVID)
2. **Descriptive compound:** Abstract concepts translated via native morphemes (kumpi = government, thudik = election)
3. **Hybrid:** Partial native + partial loan (zato inn = hospital)

Most adjectives in Zolai are stative verbs or monosyllabic roots.

| Adjective | Meaning | Example |
|-----------|---------|---------|
| `hoih` | good | `A hoih hi.` — It is good. |
| `hun` | big | `A hun hi.` — It is big. |

## 9. Linguistic Restrictions

Based on *Zolai Sinna Bu*:

1. **[t] + [i]:** These sounds do not combine in Zolai.
2. **[c] + [a, e, o, aw]:** The initial consonant `c` only pairs with `i` and `u`.
3. **[uh] + [i]:** The plural marker `uh` never co-occurs with 1st person inclusive `i`.
4. **-na / -nading:** Always join to the Stem II form (e.g., `sepna`, `hinnading`).
5. **Occupation Titles:** Always join the title to the noun (e.g., `Hausapa`, `Siavuanpa`).
6. **Clan & Place Names:** Always treat as a single joined word (e.g., `Hatlang`, `Tedim`).
7. **Complex Compounds:** Use a hyphen for clarity in long compounds (e.g., `Humpi-nelkai`).
