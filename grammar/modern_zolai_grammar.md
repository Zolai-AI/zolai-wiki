# Modern Zolai Grammar Reference
> Last updated: 2026-09-10

## Overview

This reference compares **Biblical Zolai** (formal/literary) with **Modern Zolai** (contemporary spoken/written) based on:
- **Bible corpus:** 31,102 parallel verses (TDB77, Tedim2010)
- **Zomidaily corpus:** 12,966 articles (2008-2026)
- **Total sentences analyzed:** 542,431 (31,102 + 511,329)

---

## 1. Word Order (SOV)

### Biblical Zolai — Strict SOV
```
S + O + V + (particle)
Pasian in vantung a piangsak hi.
[God] [ERG] [heaven] [3SG.AGR] [create] [DECL]
"God created heaven."
```

### Modern Zolai — Flexible SOV
```
S + O + V + (particle) — but with more topicalization
Malaysia gamsung ah naupang kum 10 khat mangcip cihthu kiza hi.
[Malaysia] [country-in] [child] [year-10] [one] [kidnap] [news] [come-PAST] [DECL]
"The news came that a 10-year-old boy was kidnapped in Malaysia."
```

### Key Differences

| Feature | Bible | Modern | Evidence |
|---------|-------|--------|----------|
| Ergative `in` frequency | ~100% of transitive | 37% of sentences | 189,358/511,329 |
| Topicalization | Rare | Common | `tua ahih pen...`, `tuaban ah...` |
| Sentence length | 8-12 words avg | 8-15 words avg | Corpus analysis |
| Loan word integration | None | Extensive | Police, Report, Social Media |

## 2. Negation

### Biblical Zolai — "lo" Dominant
```
Pai lo hi.           (go NEG) — "Goes not."
A pai lo hi.         (he go NEG) — WRONG (lo does NOT take "a")
```

### Modern Zolai — Both "kei" and "lo"
```
Ka pai kei hi.       (I go NEG) — "I don't go." ✅ Standard
Na pai kei hi.       (you go NEG) — "You don't go." ✅ Standard
A pai kei hi.        (he go NEG) — "He doesn't go." ✅ Standard
Pai lo hi.           (go NEG) — "Goes not." ✅ Literary
```

### Frequency Comparison

| Pattern | Bible | Zomidaily | Usage |
|---------|-------|-----------|-------|
| `kei` (standard) | ~500 | 22,128 (4.3%) | Spoken/written all registers |
| `lo` (literary) | ~2,000 | 30,908 (6.0%) | Formal/literary/news |
| `kei + ding` (future neg) | ~200 | ~5,000 | Future negation |
| `lo + ding` (lit. future) | ~100 | ~3,000 | Literary future |

### Critical Rule
⚠️ **"lo" does NOT take "a" agreement:**
- ✅ `Pai lo hi.` — Correct
- ❌ `A pai lo hi.` — WRONG
- ✅ `Ka pai kei hi.` — Correct (kei takes agreement)

## 3. Questions

### Yes/No Questions (hiam)

**Biblical:**
```
Na pai hiam?        (you go?) — "Do you go?"
```

**Modern:**
```
Na pai hiam?        (you go?) — "Do you go?" ✅ Same
Na UN vai Nakan Nuam hiam?  (you UN work want?) — "Do you want UN work?"
```

**Frequency:** 13,260 (2.6% of modern corpus)

### Content Questions (bang/bang hang)

**Biblical:**
```
Bang hang pai na hiam?    (what manner go you?) — "Why do you go?"
```

**Modern:**
```
Bang hang pai na hiam?    (what manner go you?) — "Why do you go?" ✅ Same
Bang pen na hiam?          (what FOC you?) — "What are you?"
```

**Frequency:** 27,567 (5.4% of modern corpus) — **HIGHER than Bible**

### Rhetorical Questions (diam)

**Biblical:**
```
Na lung a kim diam?       (you heart NEG have?) — "Don't you have a heart?"
```

**Modern:**
```
Na lung a kim diam?       Same pattern ✅
```

**Frequency:** 1,181 (0.2%)

### Question Comparison

| Type | Bible | Modern | Change |
|------|-------|--------|--------|
| hiam (yes/no) | ~3,000 (10%) | 13,260 (2.6%) | ↓ Lower proportion |
| bang (content) | ~1,000 (3%) | 27,567 (5.4%) | ↑ Higher proportion |
| diam (rhetorical) | ~100 (0.3%) | 1,181 (0.2%) | → Similar |

## 4. Tense/Aspect

### Future (ding) — Most Common

**Biblical:**
```
A pai ding hi.       (he go FUT) — "He will go."
```

**Modern:**
```
A pai ding hi.       Same pattern ✅
Kidengzan ding hi.   (fall FUT) — "Will fall."
```

**Frequency:** 97,787 (19.1%) — **Most common tense marker**

### Past (ta)

**Biblical:**
```
A pai ta hi.         (he go PAST) — "He went."
```

**Modern:**
```
A pai ta hi.         Same pattern ✅
Ka ningkhin zo hi.   (I forget COMP) — "I have forgotten."
```

**Frequency:** 15,548 (3.0%)

### Progressive (lai)

**Biblical:**
```
A ne lai hi.         (he eat PROG) — "He is eating."
```

**Modern:**
```
A ne lai hi.         Same pattern ✅
Lungsim ah gu bangin hong zen lai hi. — "Suffering in the heart continuously."
```

**Frequency:** 20,878 (4.1%)

### Completive (zo)

**Biblical:**
```
A pai zo hi.         (he go COMP) — "He has finished going."
```

**Modern:**
```
A pai zo hi.         Same pattern ✅
Ka ningkhin zo hi.   (I forget COMP) — "I have forgotten."
```

**Frequency:** 11,516 (2.3%)

### Tense Frequency Comparison

| Tense | Bible | Modern | Trend |
|-------|-------|--------|-------|
| Future (ding) | ~10,000 (32%) | 97,787 (19.1%) | ↓ Proportion ↓ but absolute ↑ |
| Progressive (lai) | ~1,500 (5%) | 20,878 (4.1%) | → Similar |
| Past (ta) | ~5,000 (16%) | 15,548 (3.0%) | ↓ Lower proportion |
| Completive (zo) | ~3,000 (10%) | 11,516 (2.3%) | ↓ Lower proportion |

## 5. Ergative System

### Biblical — Strict Ergative
```
Pasian in leitung a piangsak hi.
[God] [ERG] [earth] [3SG.AGR] [create] [DECL]
"God created the earth."
```

### Modern — Ergative with Flexibility
```
Police te'n alimzonsan mahmah alaitak ahihi.
[Police] [ERG-PL] [search-ACTIVE] [INTENS] [search] [CONT]
"The Police are actively searching."

Palik te tungah apa ii genkhiatna ah...
[Police] [to] [father] [POSS] [statement] [in]
"In the father's statement to the police..."
```

### Frequency
- **Bible:** Ergative `in` in ~100% of transitive clauses
- **Modern:** 189,358 occurrences (37% of all sentences)

### Key Insight
Modern Zolai uses ergative `in` **less frequently** because:
1. More intransitive sentences in news reports
2. Agent omission in passive constructions
3. Loan word subjects don't always take `in`

## 6. Discourse Markers

### Biblical — Minimal Discourse Markers

| Marker | Function | Frequency |
|--------|----------|-----------|
| `ahih manin` | because | ~500 |
| `tua ahih manin` | therefore | ~200 |
| `leh` | and | ~2,000 |

### Modern — Rich Discourse System

| Marker | Function | Frequency | Example |
|--------|----------|-----------|---------|
| `ahih manin` | because | 23,856 | Most common connector |
| `mahmah` | very/emphasis | 39,674 | `mahmah hi` = very good |
| `uhhi` | emphasis | 19,427 | Sentence-final emphasis |
| `ahihi` | discourse | 15,146 | Topic maintenance |
| `cihi` | sentence-final | 6,754 | Statement completion |
| `ahizongin` | moreover | 1,358 | Additive |
| `tua manin` | therefore | 30,135 | Consequence |
| `tua banah` | besides | common | Additive |
| `pen` | focus/topic | 86,994 | Very high frequency |

### Key Modern Discourse Markers

```
Tua banah — besides, moreover
Tua manin — therefore, that's why
Tua hi a — that is...
Ahizongin — moreover, furthermore
Tulaitak — especially
Tuaban — moreover, besides
```

## 8. Quotative System

### Biblical — "ci" + Speech
```
"Lungdam" ci in.    ("thanks" said) — "Saying 'thanks'."
```

### Modern — Multiple Quotative Forms

| Form | Frequency | Example |
|------|-----------|---------|
| `ci hi` | 6,834 | Statement quotation |
| `ci in` | 15,262 | Gerund quotation |
| `ci'n` | common | Contracted `ci in` |
| `ci'n genkhia` | common | "stated that..." |
| `ci'n genkhia hi` | common | "it was stated that..." |
| `ci hi` | 6,834 | Direct speech |

**Frequency:** 24,753 (4.8%)

## 9. Number System

### Biblical — Traditional Numbers
```
khat (1), nih (2), thum (3), li (4), nga (5)
panga (6), taruk (7), giat (8), ku (9), sau (10)
```

### Modern — Mixed System
```
Traditional: khat, nih, thum, li, nga, panga, taruk, giat, ku, sau
Arabic numerals: 10, 34, 2013, 2017 (in dates, phone numbers)
English numbers: "90%", "018-779 4879"
```

## 11. Key Grammar Rules (Universal)

### Rules That DON'T Change

| Rule | Pattern | Example |
|------|---------|---------|
| SOV word order | S + O + V | `Gam ka mu hi.` |
| Ergative `in` | Agent marker | `Pasian in vantung a piangsak hi.` |
| Negation (`kei`) | All persons | `Ka pai kei hi.` |
| `lo` standalone | No `a` agreement | `Pai lo hi.` (NOT `A pai lo hi.`) |
| Question (`hiam`) | End of sentence | `Na pai hiam?` |
| Content question | `bang hang` + V + S + `hiam` | `Bang hang pai na hiam?` |
| Pronoun (`a`) | Agreement marker | `A pai hi.` |
| Pronoun (`amah`) | Emphatic standalone | `Amah a pai hi.` |

### ZVS 2018 Orthography (Universal)

| Forbidden | Correct | Meaning |
|-----------|---------|---------|
| pathian | pasian | God |
| ram | gam | earth, land |
| fapa | tapa | life/son |
| bawipa | topa | Lord |
| siangpahrang | kumpipa | Savior |
| cu/cun | tua | that (conjunction) |
