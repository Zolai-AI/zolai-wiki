## Grammar Patterns Observed

### 1. SOV Word Order (Strict)

Every sentence follows Subject–Object–Verb:

```
Pasian in vantung leh leitung a piangsak hi.
[God] [ERG] [heaven] [and] [earth] [3SG.AGR] [create] [DECL]
```

### 2. Ergative `in` with Agent

All transitive subjects use `in`:

```
Pasian in ka a mu hi.      (God sees me — God is ERG agent)
Tua in hehhuai hi hiam?    (That is happy — That is ERG agent)
```

### 3. Agreement Marker `a` Before Verb

Third person uses `a` before the verb:

```
Pasian in leitung a piangsak hi.     (God created earth)
Tua in a hong piangsak hi.          (That has created)
```

### 4. Perfective `hong` (PRFV)

The perfective particle `hong` indicates completed action:

```
Lai nih in a hong hiam hi.    (Two books have asked)
Pasian in mi hong piangsak hi. (God has created people)
```

### 5. Question Formation

Yes/no questions use `hiam` at sentence end:

```
Hehhuai Hiam?                   (Happy Q?)
Tua in hehhuai hi hiam?        (Is that happy?)
```

### 6. Negation with `kei`

Standard negation for all persons:

```
Ka kei hi.    (I am not)
```

### 7. Progressive with `lai`

Aspect marking for ongoing action:

```
Ka ne lai hi.    (I am eating — from general grammar)
```

### 8. Self-Referential Identity

Series of identity statements using `ka ... hi`:

```
Ka mi hi.       (I am person)
Ka Zomi hi.     (I am Zomi)
Ka Tedim hi.    (I am Tedim)
Ka Zolai hi.    (I am Zolai)
```

## Modern Grammar Features

### Mahmah (Emphasis)

Used for emphasis or exclamation:

```
Mahmah ka lungdam hi!    (Indeed I am well!)
```

### Cih (Knowledge)

Expresses knowledge or awareness:

```
Ka cih hi.    (I know)
```

### Bel (Emphasis particle)

Intensifies the following element:

```
Bel ka hehhuai hi!    (Really I am happy!)
```

### Te'n (Possessive/Relational)

Connects possessor to possessed:

```
Ka te'n gam    (My land)
```

### Ih (Connective)

Links clauses or phrases:

```
Ka hehhuai ih lungdam hi.    (I am happy and well.)
```

### Kul (Hortative)

Encourages or urges action:

```
Ka pai kul!    (Let me go!)
```

## Prose Style Analysis

This article uses **reflective prose** with:

1. **Repetition**: "Hehhuai Hiam? Lungdam Huai Hiam?" repeated as refrain
2. **Short sentences**: 3-6 words per sentence (conversational register)
3. **Rhetorical questions**: Questions answered immediately with "Kei hi"
4. **Identity enumeration**: "Ka mi hi. Ka Zomi hi. Ka Tedim hi."
5. **Biblical echo**: "Pasian in vantung leh leitung a piangsak hi" mirrors GEN 1:1
6. **Modern particles**: Uses `mahmah`, `cih`, `bel` for contemporary voice
7. **Emotional arc**: Moves from doubt ("Hehhuai hiam? Kei hi.") to affirmation ("Ka hehhuai hi.")
