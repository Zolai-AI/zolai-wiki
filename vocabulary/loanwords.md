# Zolai Loanwords — Adopted Words (Namdanglaite Zatpihna)
> Last updated: 2026-09-10

Zolai has borrowed words from multiple languages including **English, Hindi/Urdu, Burmese, and Arabic**. The ZVS 2018 standard provides rules for adapting these words to Zolai phonology.

---

## 1. Borrowing Principles

Per ZVS 2018 (Section 3: *Namdanglaite Zatpihna*):

> "Zopau ah namdangte' lai i zatpihna ah amau malgawm bang teekteek mahin i gawmpih, i zatpih ding mah hoih penpen hi."

**Translation:** When borrowing words from other languages, we should adapt them according to their own spelling conventions — that is the best approach.

### Key Rules

1. **Adopted words follow Zolai phonology** — consonant clusters may be simplified
2. **Final consonants may be dropped** — `school` → `sikuul`
3. **Vowel harmony may apply** — vowels adjust to Zolai patterns
4. **Plural marker `te` is NOT added to borrowed nouns** — `computerte` ❌ → `computers te` ❌ → Use `computers` as is

## 7. Pluralization of Loanwords

ZVS 2018 rule: **Do NOT add `te` to borrowed nouns.**

| ❌ Incorrect | ✅ Correct | Note |
| :--- | :--- | :--- |
| `computerte` | `computers` | English plural preserved |
| `noteng` | `notes` | Use English plural |
| `busste` | `buses` | English plural |

However, when mixing Zolai and borrowed words:

| Pattern | Example | Note |
| :--- | :--- | :--- |
| Zolai + borrowed | `noteng na teng zo ding` | Zolai plural with borrowed noun |

## 8. Spelling Conventions

### A. Vowel Adaptation

| Original | Zolai | Rule |
| :--- | :--- | :--- |
| school | `sikuul` | Long vowel marked |
| tea | `cai` | Adapted to Zolai phonology |
| bus | `pas` | Simplified |

### B. Consonant Adaptation

| Original | Zolai | Rule |
| :--- | :--- | :--- |
| telephone | `tilifon` | Cluster simplified |
| computer | `komputa` | Final vowel added |
| police | `polis` | Adapted |

### C. Where `o` and `aw` Differ

| Word | Correct | Incorrect | Note |
| :--- | :--- | :--- | :--- |
| phone | `fon` | `fawn` | `o` not `aw` |
| bone | `bon` | `bawn` | `o` not `aw` |
| cow | `khaw` | `kho` | `aw` not `o` |

---

## 9. Common Mistakes

| Mistake | Correction | Rule |
| :--- | :--- | :--- |
| Adding `te` to borrowed nouns | Use English plural | ZVS 2018 Section 3 |
| Confusing `o` and `aw` | Check ZVS vowel chart | Section 2 |
| Using `f` in native words | Use `ph` or `p` | Native Zolai has no `f` |
| Using `r` in native words | Use `l` or remove | Native Zolai has no `r` |
