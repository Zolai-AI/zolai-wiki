# Zolai Etymological Dictionary
> Last updated: 2026-09-10

## Overview

This dictionary provides etymological analysis of 100+ Zolai (Tedim) words, showing compound word breakdown, derivational morphology, loan word origins, and cognates across Chin languages where known. All entries use correct ZVS 2018 orthography.

## Format

| Word | Breakdown | Origin | Cognates | Notes |
|------|-----------|--------|----------|-------|
| **vantung** | van (sky) + tung (top) | Native compound | Hakha: vantuung, Falam: vantung | "sky-top" = heaven |
| **leitung** | lei (ground/clay) + tung (above/top) | Native compound | Hakha: leitung, Falam: leitung | "ground-top" = earth |
| **pasian** | pa (father) + sian (great) | Native compound | Hakha: Pathian, Falam: Pathian | ZVS 2018: pasian ≠ pathian |
| **tapa** | ta (beginning) + pa (father) | Native compound | Hakha: thapa, Falam: thapa | ZVS 2018: tapa ≠ fapa |
| **laisiangtho** | lai (book) + siang (clean/holy) + tho (suffix) | Native compound | Hakha: laisiangtho | "holy book" = Bible |
| **topa** | to (lord/master) + pa (father) | Native compound | Hakha: bawipa, Falam: bawipa | ZVS 2018: topa ≠ bawipa |
| **kumpipa** | kum (save) + pi (give) + pa (father) | Native compound | Hakha: siangpahrang | ZVS 2018: kumpipa ≠ siangpahrang |
| **nuntakna** | nun (life) + tak (beginning) + na (nominalizer) | Native compound | Hakha: nunnak | ZVS 2018: nuntakna ≠ nunnak |
