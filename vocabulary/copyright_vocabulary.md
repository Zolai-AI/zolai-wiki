## Key Vocabulary Notes

### Polysemy

| Word | Meaning 1 | Meaning 2 | Context |
|------|-----------|-----------|---------|
| `lung` | heart (organ) | heart (emotion) | `Na lung a kim` = emotional contentment |
| `pen` | pen (writing) | focus marker | `Tua pen` = that is (focus) |
| `hi` | be (exist) | DECL particle | `Ka hi` = I am / I exist |
| `in` | in (locative) | ERG marker | `Pasian in` = God (agent) |
| `tawh` | with (instrumental) | and (connector) | `Inntek tawh` = with sincerity |

### Compound Words

| Compound | Components | Meaning |
|----------|------------|---------|
| `Lai Siangtho` | lai (book) + siang (holy) + tho (suffix) | Bible |
| `inntek vaipuak` | inntek (sincerity) + vaipuak (offering) | sincere offering |
| `theihpihna` | theih (know) + pihna (state) | knowledge/consent |
| `zahtakna` | zahtak (permit) + na (nominalizer) | permission |
| `kipilsakna` | ki (REFL) + pil (force) + sak (CAUS) + na | forcing |
| `kiphatsakna` | ki (REFL) + phat (offend) + sak (CAUS) + na | offending |
| `hawmkhia` | hawm (print) + khia (go out) | publish |
| `kikhiatsuk` | kik (back) + khia (out) + tsuk (down) | send down |
| `kibawlphat` | ki (REFL) + bawl (make) + phat (change) | reconcile |
| `siansuah` | sian (wise) + suah (holiness) | wisdom |
