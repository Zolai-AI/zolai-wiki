# zolai-wiki — Zolai knowledge base

The canonical Zolai knowledge base: grammar, vocabulary, curriculum, culture
(1529 files) — feeds school RAG context + training corpora.

## Structure
- `grammar/` — ZVS 2018 grammar, sentence structures
- `vocabulary/` — words, phrases, generated wordlists
- `training/` — curriculum, dataset specs, evaluation
- `README.md` — canonical map/index

## Enrichment
Follow `docs/WIKI_ENRICHMENT_GUIDE.md`: ZVS 2018 compliance, RAG-readiness,
curriculum linkage, dictionary reconciliation.

## Note
Wiki data may be bundled into datasets via `zolai-datasets`. Heavy/generated files are
mirrored, not duplicated here.
